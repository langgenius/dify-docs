---
title: Command Index
description: difyctl commands, grouped by job, with what each one does and what it requires
---

To see a command's flags, run `difyctl help <command>`.

In a command, `<mode>` is the app's type, such as `workflow` or `advanced_chat`. `help` lists the types each command takes, and [Find Your Apps](/en/cli/run-apps#find-your-apps) maps each one to its app type.

## Sign-In and Account

| Command | What it does | Requires |
|:--|:--|:--|
| `login` | Sign in through your browser | |
| `logout` | Sign out, ending this machine's session on the server | |
| `describe account` | Show the account you're signed in as | |
| `get account session` | List your sign-in sessions | |
| `delete account session` | End one of your sessions | |
| `delete account current_session` | End the session you're running it with | |

| Command | What it does | Requires |

## Find and Inspect Apps

| Command | What it does | Requires |
|:--|:--|:--|
| `get console_app` | List your apps with Service API access on. Filter by name or type | |
| `describe console_app` | Show an app's details and the inputs it takes | Service API access on |
| `describe app_info <mode>` | Show an app's name, description, and icon | |

## Run Apps

| Command | What it does | Requires |
|:--|:--|:--|
| `run console_app <mode>` | Run an app and get its result | Service API access on |
| `upload console_app file` | Upload a file to pass to a later run | Service API access on |
| `stop run` | Stop a run that's still going or paused at a Human Input form | Service API access on, Workflow and Chatflow apps only |
| `stop task` | Stop a reply that's still streaming | Service API access on, Chatbot, legacy Agent, and Text Generator apps only |
| `get run event` | Follow a workflow run's events | Service API access on |
| `describe run form` | Show the Human Input form a run paused at | Service API access on |
| `submit run form` | Answer a Human Input form | Service API access on |
| `get run` | List an app's runs, newest first | Service API access on, Workflow and Chatflow apps only |
| `describe run` | Show one run's inputs, outputs, error, and timing | Service API access on, Workflow and Chatflow apps only |
| `get run node` | Show each node's step in a run, to find the one that failed | Service API access on, Workflow and Chatflow apps only |

## Build and Change Apps

| Command | What it does | Requires |
|:--|:--|:--|
| `create console_app <mode>` | Create a blank Workflow app, or a Chatflow app with a starter draft | Editor or above |
| `set app_info <mode>` | Change an app's name, description, or icon | Editor or above |
| `import console_app dsl` | Create or update an app from a DSL file | Editor or above |
| `check console_app dsl` | Check a DSL file for problems without importing it | Editor or above |
| `confirm console_app dsl_import` | Finish an import waiting for confirmation, such as a file from a newer Dify version | Editor or above |
| `export console_app dsl` | Export an app's DSL | Service API access on, Editor or above |
| `check console_app dependency` | List the integrations an app needs that your workspace doesn't have | Service API access on, Editor or above |
| `get console_app env` | List the draft's environment variables, with secret values masked | Service API access on, Editor or above, Workflow and Chatflow apps only |
| `set console_app env` | Add or change an environment variable | Service API access on, Editor or above, Workflow and Chatflow apps only |
| `delete console_app env` | Remove an environment variable | Service API access on, Editor or above, Workflow and Chatflow apps only |
| `test console_app <mode>` | Test-run the draft. A run that pauses at a Human Input form can't be continued from `difyctl` | Service API access on, Editor or above |
| `test node <mode>` | Test one node of the draft | Service API access on, Editor or above |
| `get node_type` | List the node types your server can run | |
| `describe node_type` | Show a node type's settings and defaults | |
| `get knowledge_base` | List the knowledge bases you can use in a workflow | |

## Publish and Roll Back

| Command | What it does | Requires |
|:--|:--|:--|
| `check console_app release` | Check that the draft is ready to publish, and see what changed | Service API access on, Editor or above, Workflow and Chatflow apps only |
| `publish console_app` | Publish the draft | Service API access on, Editor or above, Workflow and Chatflow apps only |
| `get console_app version` | List published versions, newest first | Service API access on, Editor or above, Workflow and Chatflow apps only |
| `restore console_app version` | Copy a published version into the draft. Publish to make it live | Service API access on, Editor or above, Workflow and Chatflow apps only |

## Agent Knowledge Bases <Badge color="blue">Cloud</Badge>

The `knowledge_fs` commands read an agent knowledge base you can view in Dify. For how to point your coding agent at one, see [From Your Coding Agent](/en/cloud/use-dify/knowledge-base/use-knowledge-in-apps#from-your-coding-agent).

| Command | What it does | Requires |
|:--|:--|:--|
| `knowledge_fs ls` | List a knowledge base's documents, or the sections of one | |
| `knowledge_fs tree` | Show documents and their sections as one nested list | |
| `knowledge_fs find` | Find documents by name or metadata | |
| `knowledge_fs grep` | Search documents for exact words | |
| `knowledge_fs cat` | Print a document or one of its sections | |
| `knowledge_fs stat` | Show a document's details, such as whether it finished processing | |
| `knowledge_fs diff` | Compare two documents | |
