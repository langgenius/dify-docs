<Tip>

</Tip>

`difyctl` is the Dify command-line interface (CLI). It lets you work with your Dify apps from a terminal instead of the browser, and hand the same work to a coding agent, a script, or a CI job.

You set it up once: install it, sign in, and give your coding agent the `difyctl` skill. Then ask your agent to build, run, or update your apps.

Sign-ins expire, and [renewing one](/en/cli/manage-sign-in#renew-your-sign-in) takes a person in a browser. If your code runs only one app, use the [Service API](/en/api-reference/guides/get-started) instead: its key never needs renewing.

To start:

- New to `difyctl`: follow [Get Started](/en/cli/get-started).
- Used it before your server moved to Dify 1.18.0: start from [Upgrade Across Dify 1.18.0](/en/cli/upgrade-across-1-18).
- Server on Dify 1.17.x or earlier: use the [docs for that version](https://github.com/langgenius/dify-docs/branches/all?query=release%2F).
