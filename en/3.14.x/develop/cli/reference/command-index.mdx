| Command | What it does |
|:---|:---|
| [`auth devices list`](/en/3.14.x/develop/cli/reference/auth-and-contexts#list-your-active-sessions) | List the active sessions for your account. |
| [`auth devices revoke`](/en/3.14.x/develop/cli/reference/auth-and-contexts#revoke-sessions) | Revoke one session, or all but the current one. |
| [`auth list`](/en/3.14.x/develop/cli/reference/auth-and-contexts#list-your-saved-contexts) | List your saved sign-in contexts. |
| [`auth login`](/en/3.14.x/develop/cli/reference/auth-and-contexts#sign-in) | Sign in to a Dify host with the OAuth device flow. |
| [`auth logout`](/en/3.14.x/develop/cli/reference/auth-and-contexts#sign-out) | Sign out of the active host. |
| [`auth whoami`](/en/3.14.x/develop/cli/reference/auth-and-contexts#check-your-active-identity) | Print the identity you're signed in as. |
| [`describe app`](/en/3.14.x/develop/cli/reference/apps#inspect-an-app) | Inspect one app's metadata and inputs. |
| [`env list`](/en/3.14.x/develop/cli/reference/environment-variables#see-whats-set) | List the environment variables difyctl recognizes. |
| [`export studio-app`](/en/3.14.x/develop/cli/reference/apps#export-an-app) | Export a studio app's DSL configuration as YAML. |
| [`get app`](/en/3.14.x/develop/cli/reference/apps#list-your-apps) | List apps, or look up one app. |
| [`get workspace`](/en/3.14.x/develop/cli/reference/workspaces#list-your-workspaces) | List your workspaces. |
| [`help`](/en/3.14.x/develop/cli/reference/help) | Get help in the terminal, including machine-readable JSON. |
| [`knowledge fs cat`](/en/3.14.x/develop/cli/reference/knowledge#print-a-document) | Print a document, a section, or the outline from a knowledge base. |
| [`knowledge fs diff`](/en/3.14.x/develop/cli/reference/knowledge#compare-two-documents) | Compare two files in a knowledge base line by line. |
| [`knowledge fs find`](/en/3.14.x/develop/cli/reference/knowledge#find-files-by-name-or-metadata) | Find files in a knowledge base by name or metadata. |
| [`knowledge fs grep`](/en/3.14.x/develop/cli/reference/knowledge#search-for-text) | Search a knowledge base's documents for text. |
| [`knowledge fs ls`](/en/3.14.x/develop/cli/reference/knowledge#list-documents) | List the documents in a knowledge base, or a document's parts. |
| [`knowledge fs stat`](/en/3.14.x/develop/cli/reference/knowledge#check-a-documents-details) | Show a file's processing status and details. |
| [`knowledge fs tree`](/en/3.14.x/develop/cli/reference/knowledge#show-the-folder-tree) | Show a knowledge base's folders as a tree. |
| [`import studio-app`](/en/3.14.x/develop/cli/reference/apps#import-an-app) | Import a studio app from a DSL file or URL. |
| [`resume app`](/en/3.14.x/develop/cli/reference/apps#resume-a-paused-workflow) | Resume a paused workflow run. |
| [`run app`](/en/3.14.x/develop/cli/reference/apps#run-an-app) | Run an app and print the response. |
| [`skills install`](/en/3.14.x/develop/cli/reference/skills#install-the-skill) | Install the difyctl skill into detected coding agents. |
| [`use account`](/en/3.14.x/develop/cli/reference/auth-and-contexts#switch-the-active-account) | Switch the active account on the current host. |
| [`use host`](/en/3.14.x/develop/cli/reference/auth-and-contexts#switch-the-active-host) | Switch the active Dify host. |
| [`use workspace`](/en/3.14.x/develop/cli/reference/workspaces#switch-your-workspace) | Switch your active workspace. |
| [`version`](/en/3.14.x/develop/cli/reference/version) | Show client and server versions and compatibility. |

[Global flags](/en/3.14.x/develop/cli/reference/global-flags) work across commands.

For the output formats, errors, and exit codes, see [Output Formats and Exit Codes](/en/3.14.x/develop/cli/reference/output-formats-and-exit-codes).
