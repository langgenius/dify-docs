Whether retrieval can work with images depends on the models you picked for the knowledge base. Start from what you want retrieval to do with images:

- **Text-to-image search**: a text question finds images in the knowledge base by what they show.

    Pick a vision-capable *embedding* model. It indexes each image as a vector, so a question like "the org chart" can match a diagram even if it has no caption or alt text.

- **Image-to-image search**: an attached image finds visually similar images in the knowledge base.

    Pick a vision-capable *embedding* model, so similar images match even when they share no text.

- **Image-to-text search**: an attached image finds relevant text chunks.

    Pick a vision-capable *reasoning* model. It describes the image in words and searches that description against text.

For all three, pick vision-capable models for both embedding and reasoning. Either model can be changed later under **Settings** > **Retrieval**, but changing it re-indexes every document and costs tokens.

## How Models Affect Image Behavior

| | Images are extracted | Text finds image | Image finds text | Image finds image |
|:--|:--|:--|:--|:--|
| **Both support vision** | Yes | By appearance and by parser text | Deep and Research: yes. <br/><br/>Fast: no, image queries find images only. | Yes |
| **Embedding only** | Yes | By appearance and by parser text | No | Yes |
| **Reasoning only** | Yes | By parser text only | Yes | No |
| **Neither** | As placeholders only, without the image itself | By parser text only | No. <br/><br/>Image-only queries fail, and images on a text query are ignored. | No |

*Parser text* is any caption, alt text, or OCR text the document parser pulls out of the file. It is searchable regardless of model choice, so well-captioned source documents improve image retrieval in every combination.

<Info>
To enable OCR for images in PDF and DOCX files, configure the Unstructured service with the `hi_res` strategy. See [Unstructured Parser](/en/3.14.x/deploy/advanced-configuration/environment-variables#unstructured-parser) in Environment Variables for the setup.

Captions and alt text are extracted natively for common formats like Markdown, HTML, and DOCX without extra configuration.
</Info>
