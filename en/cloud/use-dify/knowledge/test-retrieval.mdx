title: Test Knowledge Retrieval
sidebarTitle: Test Retrieval
---

In a knowledge base, click the **Retrieval Testing** icon in the left sidebar to enter the testing page. 

Enter questions your users might ask, including different ways to ask for the same information. Run each test, then check whether the returned text chunks contain the information needed to answer the question. If they do not, try changing Top K to adjust the maximum number of returned chunks, then repeat the same questions and compare the results.

<Note>
    Retrieval settings adjusted here are temporary and only apply to the current test session.
</Note>

<Tip>
    For more about retrieval settings, see [Configure the Retrieval Settings](/en/cloud/use-dify/knowledge/create-knowledge/setting-indexing-methods#configure-the-retrieval-settings).
</Tip>

The **Records** section logs all retrieval events associated with this knowledge base, including:

- Queries tested directly on the **Retrieval Testing** page
- Retrieval requests made by any linked app—whether during test runs or in production

<Info>
    Test retrievals and regular retrievals share the same API endpoint.
</Info>
