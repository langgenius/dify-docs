模型为你在 Dify 中构建的众多应用和功能提供支持。Dify Cloud 提供两种模型访问方式：使用套餐包含的 AI 消息额度调用受支持的模型，或添加自己的 API Key 连接模型供应商账户。

无论采用哪种方式，这些模型都可在整个工作空间中使用。

## 使用 AI 消息额度

使用 AI 消息额度时，无需添加 API Key 即可调用不同模型供应商的受支持模型。从 **集成** > **模型供应商**（或 [Marketplace](https://marketplace.dify.ai/)）安装其中一个供应商，其模型即可使用。

额度消耗和使用规则详见 [AI 消息额度](/zh/cloud/use-dify/workspace/ai-credits)。

## 使用自己的 API Key

先在模型供应商的账户或开发者控制台中创建 API Key，再将其添加到 Dify，即可通过该账户调用模型。

<Note>
只有工作空间所有者和管理员可添加或管理模型供应商 API Key。
</Note>

1. 前往 **集成** > **模型供应商**。

2. 找到目标模型供应商。若尚未安装，可在 **安装模型供应商** 下选择它，也可前往 [Marketplace](https://marketplace.dify.ai/) 查找。

3. 点击 **添加 API 密钥**，输入 API Key，并填写该模型供应商要求的其他信息。

如果模型供应商支持 AI 消息额度，两种方式都可使用。通过 [使用优先级](/zh/cloud/use-dify/workspace/ai-credits#设置使用优先级) 选择优先使用哪一种。

模型供应商会记录通过你自己的 API Key 发出的请求，并向你的供应商账户收费。这些请求不会扣除 AI 消息额度。对于不支持 AI 消息额度的模型供应商，API Key 是唯一选择。

## 添加自定义模型

模型供应商连接后，其模型即可使用。只有在所需模型未列出时，例如刚发布或微调的模型，才需要手动添加。

点击模型供应商卡片上的 **添加模型**，然后根据表单填写模型信息和凭据。必填字段取决于模型供应商和模型。仅提供固定模型列表的模型供应商不会显示此选项。

<Info>
如果添加的模型与现有模型的名称和类型相同，Dify 会将新的 API Key 关联到该模型，而不会创建重复模型。
</Info>

## 选择应用默认使用的模型

未指定模型的应用和节点会改用工作空间的默认模型。点击右上角的 **默认模型设置**，为以下用途分别设置默认模型：

- **系统推理模型**：常规 LLM 任务使用的默认模型。
- **Embedding 模型**：用于索引和检索知识库内容。
- **Rerank 模型**：按相关性重新排列检索结果。
- **语音转文本模型**：将音频转换为文本。
- **文本转语音模型**：将文本转换为音频。

## 通过负载均衡将请求分散到多个 API Key <Badge color="blue">Professional</Badge> <Badge color="blue">Team</Badge>

当一个 API Key 同时处理大量请求时，可能触发模型供应商的速率限制，导致请求失败。

使用负载均衡将同一模型的请求分散到多个 API Key，避免单个 API Key 成为瓶颈。Dify 会轮流使用这些 API Key。某个 API Key 触发速率限制后，Dify 会暂停使用它 1 分钟，然后再尝试。

1. 在列表中找到模型，点击 **配置**，然后选择 **负载均衡**。

2. 点击 **添加凭据**，将 API Key 添加到凭据池。

    <Tip>
    如果某个 API Key 的配额更高或速度更快，可多次添加，让它分配到更多流量。
    </Tip>

    <Frame>
    ![为负载均衡添加凭据](/images/use-dify/workspace/add-load-balancing-credential.png)
    </Frame>

3. 启用至少 2 个 API Key，然后点击 **保存**。使用负载均衡的模型会在列表中显示标记。

<Info>
你可随时切换回单个 API Key，负载均衡设置会保留，供以后使用。
</Info>
