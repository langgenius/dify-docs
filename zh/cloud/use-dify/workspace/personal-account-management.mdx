你的个人账户跨越你所属的所有工作空间。个人资料设置、语言偏好和登录凭据会跟随你到任何地方，而每个工作空间都保持其自己的团队动态和权限。

## 账户设置

首次登录时会自动创建账户。你可以使用 GitHub、Google 或邮箱验证码登录。邮箱地址相同的账户会自动关联：例如先用 `you@company.com` 通过 GitHub 注册，之后再用同一地址进行邮箱验证登录，系统会识别为同一账户。

## 多工作空间访问

你的个人账户可以属于多个工作空间。每个工作空间都有自己的团队、应用和计费，但你的个人资料在所有工作空间中保持一致。

**切换工作空间**：使用左上角的工作空间选择器在你有权访问的工作空间之间切换。

**工作空间独立性**：你的角色和权限是按工作空间设置的。你可能在一个工作空间中是所有者，在另一个工作空间中是成员。

## 个人资料管理

在设置 → 账户 → 个人资料中更新你的个人资料信息。更改适用于你所属的所有工作空间。

**头像**：上传自定义头像。这将替换默认的基于姓名首字母的头像，并在所有工作空间中显示。

**显示名称**：你在所有工作空间中向团队成员显示的名称。选择能够帮助队友识别你的名称。

**邮箱地址**：你的主要登录凭据和唯一标识符。更改你的邮箱会影响使用旧地址的所有工作空间。

## 语言和界面

**显示语言**：可用语言包括英语、简体中文和繁体中文。此设置影响界面元素，但不影响你的应用内容。

**更改语言**：点击你的头像 → 语言，然后选择你偏好的语言。

## 登录方式

可使用以下任一方式登录：

- **GitHub**：通过你的 GitHub 账户进行 OAuth 登录。
- **Google**：通过你的 Google 账户进行 OAuth 登录。
- **邮箱验证码**：一次性验证码会发送到你的邮箱地址。

## 个人访问令牌

有了个人访问令牌，脚本、CI 任务和编码 Agent 不用登录，也能通过 [`difyctl`](/zh/cli/get-started) 以你的身份操作。所有成员都可在自己的 **账户** 页面创建令牌。

### 创建令牌

点击 **创建令牌**，只给令牌开放任务需要的权限：任何人拿到它，都能做它允许的所有事。

- **有效期**：选一个能覆盖任务运行时长的期限，不要选 **永不**。有效期创建后无法修改；如果任务运行得比它久，就 [替换令牌](#修改、替换或删除令牌)。
- **资源**：令牌可运行的应用。
- **管理工作空间**：令牌可以在哪些工作空间里配置集成，例如模型和工具。

**资源** 和 **管理工作空间** 各自允许哪些 `difyctl` 命令，详见 [选择账户和访问范围](/zh/cli/personal-access-tokens#选择账户和访问范围)。

即使在访问范围之内，令牌在每个工作空间中也只能做你的角色允许的事。你的角色变更，或你被移出某个工作空间，都会从令牌下次使用时生效。

创建完成后，[把令牌交给 `difyctl`](/zh/cli/personal-access-tokens#把令牌交给-difyctl)。

### 修改、替换或删除令牌

- **修改名称或访问范围**：新的访问范围从令牌下次使用时生效，任务继续使用原来的令牌。
- **在到期前替换**：复制该令牌的配置生成新令牌，让任务改用新令牌，再删除旧令牌。
- **删除**：令牌立即失效，但已在进行中的运行仍会执行完。

## 安全

社交登录（GitHub 或 Google）沿用你所选供应商的安全机制。可在该供应商的平台上检查安全设置并监控登录活动。

你的个人设置会跟随你到任何地方，但每个工作空间都有自己的角色和权限。

<Warning>
更改你的邮箱地址会影响所有工作空间。如果你只想为某个工作空间更改邮箱，请考虑让该工作空间邀请新邮箱作为单独的用户账户。
</Warning>
