<Note>
    知识库创建后，其数据源无法更改。
</Note>

创建即用型知识库时，可上传本地文件作为其数据源。

<Tip>
    如需扫描文件中的恶意软件，可改为创建空知识库，在其设置中 [开启文件安全扫描](/zh/cloud/use-dify/knowledge/file-security-scan#为知识库开启扫描)，然后上传文件。
</Tip>

1. 点击 **知识库** > **创建** > **创建即用型知识库**。

2. 选择 **导入已有文本** 作为数据源，然后上传文件。

上传限制因套餐而异：

| | Sandbox | Professional 和 Team |
|:--|:--|:--|
| 单次上传文件数 | 1 | 50 |
| 单个文件大小 | 15 MB | 50 MB |
---

**上传文件中的图片**

    JPG、JPEG、PNG 和 GIF 格式且小于 2 MB 的图片将作为附件，自动提取到对应的分段。这些图片可独立管理，并在检索时与分段一同返回。

    提取出的图片 URL 会保留在分段文本中。如需保持文本整洁，可放心删除这些 URL，已提取的图片不受影响。

    若在索引设置中选择多模态嵌入模型（带有 **Vision** 图标），Dify 还会为提取出的图片生成嵌入并建立索引，供检索使用。

    每个分段最多支持 10 个图片附件，超出的图片不会提取。

    以上提取规则适用于如下图片类型：

    - DOCX 和 XLSX 文件中嵌入的图片

        <Tip>
            如需提取其他文件类型（如 PDF）中嵌入的图片，可在 [知识流水线](/zh/cloud/use-dify/knowledge/knowledge-pipeline/readme) 中使用合适的文档提取插件。
        </Tip>

    - 在任何文件类型中，通过以下 Markdown 语法引用、URL 可访问的图片：

        - `![alt text](image_url)`
        - `![alt text](image_url "optional title")`
