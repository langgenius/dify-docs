在经典知识库中，内容如何分段、索引和检索，都由你自己决定。它还能接入你已在运行的知识库，由 Dify 直接在其中检索，无需把内容复制过来。

聊天助手、文本生成应用和旧版 Agent 应用都可基于它作答，Workflow 和 Chatflow 应用也可通过知识检索节点使用它。

<Tip>

- 如需与 Agent 知识库比较，参见 [该创建哪一类知识库](/zh/cloud/use-dify/knowledge/overview#choose)。

- 即用型经典知识库可 [升级](/zh/cloud/use-dify/knowledge-base/upgrade-from-classic) 为 Agent 知识库，外部知识库和用知识流水线构建的知识库则不行。

</Tip>

## 创建知识库 {#set-up}

- **[创建即用型知识库](/zh/cloud/use-dify/knowledge/create-knowledge/introduction)**：导入数据，再设定内容如何分段、索引和检索。

- **[构建自定义知识库](/zh/cloud/use-dify/knowledge/knowledge-pipeline/readme)**：标准设置不适合你的内容时，可用知识流水线设计专属的处理流程，自行选择数据源，以及提取、分段和索引内容的每个步骤。

- **[连接外部知识库](/zh/cloud/use-dify/knowledge/connect-external-knowledge-base)**：通过 API 检索你已在运行的知识库，无需把内容迁入 Dify。

## 测试与改进

- **[测试召回效果](/zh/cloud/use-dify/knowledge/test-retrieval)**：拿用户可能会问的问题试一试，看看会返回哪些分段。

- **[调整知识库设置](/zh/cloud/use-dify/knowledge/manage-knowledge/introduction)**：更换嵌入模型、修改检索设置，或将索引方式从「经济」切换为「高质量」。

- **[利用元数据增强检索](/zh/cloud/use-dify/knowledge/metadata)**：为文档标注元数据，让检索只在符合条件的文档中进行。

## 使用与维护

- **[集成到应用](/zh/cloud/use-dify/knowledge/integrate-knowledge-within-application)**：将它接入应用，并设置应用如何从中检索。

- **[维护知识库内容](/zh/cloud/use-dify/knowledge/manage-knowledge/maintain-knowledge-documents)**：内容有变化时，添加、编辑、禁用或删除文档和分段。
