每个知识库都可在索引上传的文件之前，先扫描其中是否含有恶意软件。工作空间所有者或管理员先为工作空间接入一个或多个扫描服务，之后需要扫描的知识库即可各自开启。

扫描仅覆盖上传至经典知识库和 Agent 知识库的文件，包括知识流水线中通过本地文件数据源上传的文件。知识库从 Notion、网页抓取、在线文档或在线网盘导入的内容不在扫描范围内，发送给应用、工作流或对话的文件也不会扫描。

## 接入扫描服务

在 **集成** > **文件安全扫描** 中点击 **添加扫描服务**，然后选择类型。选哪种，取决于文件允许发往哪里：

- **Cloudmersive**、**Scanii** 或 **MetaDefender Cloud**：托管扫描服务，需要你在该服务开通账号。每个文件的内容都会发往该服务。

  每扫描一个文件都会消耗你在该服务的额度，而且任何能编辑知识库设置的成员都能用它开启扫描。套餐用量应按所有可能用到它的知识库来估算。

- **自定义端点**：公司自有的扫描服务。

  该服务必须能从公网访问。如果它只运行在公司内网中，需要先为它配置公网地址。该服务需要处理的请求和响应格式详见 [自定义端点扫描服务 API](/zh/cloud/use-dify/knowledge/file-security-scan-custom-endpoint)。

保存扫描服务时，Dify 会测试连接，测试不通过就无法保存。

## 为知识库开启扫描

在知识库的 **设置** 中找到 **文件安全扫描**：开启扫描，选择 **扫描服务**，设置 [下面两个选项](#选择未扫描文件的处理方式)，最后保存。

扫描对开启之后上传的文件生效。要让每个文件都经过扫描，可先创建一个空知识库，开启扫描后再上传文件。

知识库中已有的文档会怎样处理，取决于知识库的类型：

- **经典知识库**：文档会在下次处理时扫描，比如重试或分段设置变更时。如果检测到感染，该文档会显示 **错误**。
- **Agent 知识库**：已有文档始终不会扫描，即使重试或重新索引也一样。

如需立即扫描某个已有文档，可将其删除，再重新上传该文件。

### 选择未扫描文件的处理方式

扫描在以下两种情况下无法给出结果，可分别选择拦截文件，或不经扫描直接放行：

- **扫描服务不可用时**：扫描服务无法连接、请求超时、返回服务器错误，或返回 Dify 无法解析的结果。
- **文件无法扫描时（已加密或过大）**：文件已加密或设有密码保护、超出扫描服务可接受的大小，或属于扫描服务不支持的类型。

仅当文件入库比逐个扫描更重要时，才将任一选项改为 **放行文件**。比如某个知识库在扫描服务停机期间也必须保持最新，或者经常要接收超出扫描服务大小上限的文件。这样放行的文件会跳过扫描直接索引，也没有任何标记表明它们未经扫描。

无论怎么选，Dify 始终会拦截检测出恶意软件的文件。扫描服务的凭据被拒绝或额度已用完时，发往该服务的文件也一样。

### 验证扫描是否生效

从 [eicar.org](https://www.eicar.org) 下载 EICAR 测试文件。这个文件本身无害，但所有杀毒引擎都会把它识别为恶意软件。将它保存为 `.txt` 文件，再上传到知识库。该文件应被拦截，并提示检测到恶意软件。

如果文件照常完成了索引：

- 检查上传文件之前，是否已开启扫描并保存了设置。
- 检查该知识库的 **扫描服务不可用时** 选项。选的若是 **放行文件**，扫描服务没有响应时，文件会不经扫描直接入库。工作空间所有者或管理员可在 **集成** > **文件安全扫描** 中点击该扫描服务的 **测试**，看它能否响应。

## 处理被拦截的文件

如果是文件本身导致了拦截，按拦截原因处理：

- **检测到恶意软件**：不要把这个文件放入知识库。重试或重新上传同一文件，只会再次被拦截。

- **已加密、过大或扫描服务不支持**：这类文件默认会被拦截。如果可以接受它们不经扫描进入知识库：

  1. 将该知识库的 **文件无法扫描时（已加密或过大）** 选项改为 **放行文件** 并保存。
  2. 在经典知识库中，重试该文档；在 Agent 知识库中，移除该文件后重新上传。
  3. 文件入库后，如果只是为这一个文件临时放行，记得把选项改回来。否则，该选项会对知识库之后的所有文件生效。
