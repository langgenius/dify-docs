即使应用链接被转发，也可将访问范围限制为办公网络、指定服务器等可信网络。

先在工作空间设置中创建 IP 策略，再将策略应用到各个应用中需要保护的访问入口。同一策略可供工作空间内的多个应用使用。

<Info>
IP 访问控制适用于 Professional 和 Team 套餐。

只有工作空间所有者和管理员可创建、编辑或删除 IP 策略。有权管理应用访问入口的编辑成员可使用现有策略配置该应用的访问控制。
</Info>

## 管理 IP 策略

打开工作空间 **设置** > **IP 策略**。

### 创建 IP 策略

点击 **创建 IP 策略**；如果工作空间已有策略，则点击 **添加**。输入 **名称**，将要允许的地址添加到 **允许列表**：

- 要允许当前使用的网络，点击当前 IP 地址旁的 **添加**。
- 向需要访问应用的网络或系统的负责人确认其公网 IP 地址。

可输入单个 IPv4 或 IPv6 地址，也可用 CIDR 表示法输入地址范围。添加地址范围后，策略会允许来自该范围内所有 IP 地址的请求。

点击 **创建**。要使用这份策略，需 [为应用配置访问控制](#配置应用访问控制)。

### 更改允许的 IP 地址

在 **IP 策略** 中选择策略，更新 **允许列表**，然后点击 **保存**。

更改会影响所有使用这份策略的应用，无需重新发布即可生效。

### 删除 IP 策略

删除后无法恢复，所有使用这份策略的应用都将失去 IP 访问保护。要继续保护这些应用，需在删除前 [为它们更换策略](#更换策略或受保护的访问入口)。

在 **IP 策略** 中，打开策略的 **…** 菜单，选择 **删除** 并确认。

## 配置应用访问控制

如果 **设置** 还开着，先关闭它。从 **工作室** 打开要保护的应用，或从 **Agents** 打开你的 Agent。

在应用的 **访问入口** 标签页中，点击右上角的 **访问控制**。

### 设置访问控制

1. 在 **IP 策略** 下选择要使用的策略。
2. 在 **应用于** 下，开启要通过这份 IP 策略保护的访问入口，然后点击 **保存**。未选中的入口不受这份策略限制。

要检查设置，请分别从允许的网络和允许范围之外的网络测试选中的访问入口。

<Tip>
点击 **IP 策略** 旁的 **管理 IP 策略** 图标，会打开工作空间设置并关闭 **访问控制**。完成操作后，关闭 **设置**，返回应用的 **访问入口** 标签页，再次点击 **访问控制**。
</Tip>

### 更换策略或受保护的访问入口

在 **访问控制** 中，点击 **编辑**，调整 **IP 策略** 或 **应用于** 下的选择，然后点击 **保存**。

保存也会重新启用已暂停的访问控制。

### 暂停或恢复访问控制

在 **访问控制** 中，关闭 **按 IP 地址限制访问** 并确认。重新开启开关即可恢复。

暂停期间，IP 限制停止生效，但设置会保留。

<Warning>
Professional 或 Team 订阅失效时，IP 访问保护也会停止生效，但设置会保留。续订或升级到其中任一套餐，即可重新使用 IP 访问保护。
</Warning>
