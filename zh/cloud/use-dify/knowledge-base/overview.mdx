Agent 知识库会替你处理内容，由推理模型逐篇阅读并整理文档，再由嵌入模型让文档可供检索。你要做的不多：决定放入哪些内容，设定检索深度，再检查返回的结果。

在默认深度下，检索会按语义和关键词匹配内容。把 [检索深度](/zh/cloud/use-dify/knowledge-base/retrieval-settings#retrieval-depth) 调深后，知识库会像 Agent 一样探究问题：跨文档追踪相关主题，或者把问题拆成几部分，再阅读完整的章节。

除了应用，你本机上的编码 Agent 也能通过 [Dify CLI](/zh/cloud/use-dify/knowledge-base/use-knowledge-in-apps#from-your-coding-agent) 读取其中的文档，像浏览文件夹里的文件一样。

<Tip>

- 如需与经典知识库比较，参见 [该创建哪一类知识库](/zh/cloud/use-dify/knowledge/overview#choose)。

- 如需把经典知识库迁移过来，参见 [如何升级](/zh/cloud/use-dify/knowledge-base/upgrade-from-classic)。

</Tip>

## 创建与配置

- **[创建 Agent 知识库](/zh/cloud/use-dify/knowledge-base/create-knowledge-base)**：连接网站、在线文档或在线云盘，让内容按你设定的频率同步；也可直接上传文件。

- **[检查已索引的文档](/zh/cloud/use-dify/knowledge-base/review-indexed-documents)**：查看文档是如何拆分、如何生成摘要的，并修正处理得不理想的地方。

- **[配置图片检索](/zh/cloud/use-dify/knowledge-base/multimodal-retrieval)**：选择合适的模型，让检索也能处理图片。

## 测试与改进

- **[测试并调优检索](/zh/cloud/use-dify/knowledge-base/test-and-tune)**：拿用户可能会问的问题来测试，并把每次改动后都必须通过的问题保存为参考问题。

- **[调整检索设置](/zh/cloud/use-dify/knowledge-base/retrieval-settings)**：选择模型和检索深度，设定返回多少个分段，以及分段至少要匹配到什么程度。

## 使用与维护

- **[接入应用、Agent 和代码](/zh/cloud/use-dify/knowledge-base/use-knowledge-in-apps)**：将它添加到工作流和新 Agent 中，在自己的代码里调用它，或让编码 Agent 读取它。

- **[维护 Agent 知识库](/zh/cloud/use-dify/knowledge-base/maintain-knowledge-base)**：应用开始依赖知识库后，持续监控它，处理出现的问题，并让内容保持最新。
