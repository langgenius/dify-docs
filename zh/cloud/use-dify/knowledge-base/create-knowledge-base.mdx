前往 **知识库**，切换到 **Agent**，然后点击 **创建**。

## 设置基本信息

为知识库填写名称和描述，并设定哪些成员能查看它、把它接入自己的应用。以上各项之后都可在知识库的设置中修改。

知识库使用工作空间的默认模型。要让文档中的图片也能被检索到，需要使用 [支持视觉的嵌入模型](/zh/cloud/use-dify/knowledge-base/multimodal-retrieval)。如果添加内容之后才换用这类模型，所有文档都会重新索引。

## 添加内容

内容存放在别处且会持续变化时，连接数据源；手头是独立的文档时，直接上传文件。一个知识库可同时包含这两类内容。

<Tip>
先导入少量有代表性的文档，等检索调优到位后再导入其余内容。之后更换嵌入模型或推理模型都会重新索引所有文档，趁知识库还小时更换，消耗的 token 也更少。
</Tip>

### 连接数据源 {#connect-a-source}

数据源借助 Firecrawl、Notion、Google Drive 等数据源集成，从网站、文档平台或云盘导入内容。

<Steps>
  <Step title="选择提供商">
    从工作空间已安装的数据源集成中选择一个，或点击 **更多提供商** 浏览并安装新的集成。

    <Tip>
    如果现有集成都满足不了需求，可以 [自行开发](/zh/develop-plugin/dev-guides-and-walkthroughs/datasource-plugin)，或向社区 [提出需求](https://github.com/langgenius/dify-plugins/issues/new?template=plugin_request.yaml)。
    </Tip>

    然后在 **集成** > **数据来源** 中输入对应的 API 密钥或授权账号，完成连接。

  </Step>
  <Step title="选择要同步的内容">
    <Tabs>
      <Tab title="网站抓取">
        1. 为数据源命名并粘贴 URL，然后检查 **抓取选项** 中的默认设置，按需调整。

        2. 点击 **抓取并预览**，从结果中选择要导入的页面。
      </Tab>
      <Tab title="在线文档">
        从已连接的账号中选择要导入的页面。
      </Tab>
      <Tab title="在线云盘">
        从已连接的云盘或存储桶中选择要导入的文件。
      </Tab>
    </Tabs>
  </Step>
  <Step title="设置同步策略">
    选择预设的同步周期，设置自定义间隔（1 小时至 30 天），或改为手动同步。

    同步频率按内容的更新频率来定。同步时发现变化，就会重新索引有变化的内容，这会消耗 token。
  </Step>
</Steps>

### 上传文件

单个文件最大 15 MB。

<Tip>
批量上传适用于 <Badge color="blue" size="sm">Professional</Badge> 和 <Badge color="blue" size="sm">Team</Badge> 套餐。[了解更多](https://dify.ai/pricing)。
</Tip>

## 后续步骤

在 **文档** 页面看到文档显示为 **就绪** 后，还要完成三步，知识库才适合面向真实用户：

1. [检查已索引的文档](/zh/cloud/use-dify/knowledge-base/review-indexed-documents)：打开文档，确认章节、摘要和分段都处理得当。

2. [测试检索并调优设置](/zh/cloud/use-dify/knowledge-base/test-and-tune)：提出应用实际会遇到的问题，反复调优，直到结果稳定可靠。

3. [接入应用、Agent 和代码](/zh/cloud/use-dify/knowledge-base/use-knowledge-in-apps)：把它添加到需要依据它作答的应用中。
