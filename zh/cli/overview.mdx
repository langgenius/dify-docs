`difyctl` 是 Dify 的命令行界面（CLI）。有了它，不用打开浏览器，在终端里就能操作 Dify 应用，同样的工作还能交给编码 Agent、脚本或 CI 任务去做。

准备工作只需做一次：安装 difyctl 并登录，再为编码 Agent 配置 `difyctl` Skill。之后让 Agent 去构建、运行或更新你的应用即可。

登录会过期，而 [续期登录](/zh/cli/manage-sign-in#续期登录) 需要有人在浏览器中操作。如果你的代码只运行一个应用，就改用 [服务 API](/zh/api-reference/guides/get-started)：它的密钥无需续期。

开始使用：

- 初次使用 `difyctl`：按 [快速开始](/zh/cli/get-started) 操作。
- 在服务器升级到 Dify 1.18.0 之前就用过 `difyctl`：先从 [Dify 1.18.0 升级指南](/zh/cli/upgrade-across-1-18) 开始。
- 自部署的服务器运行 Dify 1.17.x 或更早版本：改用 [该版本对应的文档](https://github.com/langgenius/dify-docs/branches/all?query=release%2F)。
