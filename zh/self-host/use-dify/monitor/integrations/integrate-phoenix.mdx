### Phoenix 简介

[Arize Phoenix](https://arize.com/phoenix/) 是 [Arize AI](https://arize.com/?utm_source=dify-docs&utm_medium=partner&utm_campaign=partner-docs&utm_content=integrate-phoenix-self-host) 推出的开源平台，基于 OpenTelemetry 构建，为 LLM 工作流和 Agent 提供可观测性、评估、提示工程和实验能力。

开发阶段可在本地运行 Phoenix，也可在自有基础设施上以单容器方式自部署，或使用 Arize 托管的 [Phoenix Cloud](#配置-phoenix-cloud)。

如需面向生产环境团队、AI 原生公司和企业的全功能平台，可改用 [Arize 集成](/zh/self-host/use-dify/monitor/integrations/integrate-arize) 接入 [Arize AX](https://arize.com/products/ax/)。

追踪数据接入后，可参考 Arize 的 [Agent 评估指南](https://arize.com/guides/ai-agent-handbook/agent-evaluation/) 和 [LLM 评估指南](https://arize.com/resources/llm-evaluation/)，了解如何用追踪数据调试故障、评估 Agent 行为、监控模型质量。

### 配置 Phoenix

本章节将指引你注册 Phoenix 并将其集成至 Dify 平台内。

如果自部署的 Phoenix 实例未启用身份验证，可跳过以下账户和 API 密钥步骤，并将 **API Key** 留空。

#### 1. 注册/登录 [Phoenix](https://app.arize.com/auth/phoenix/signup)

### 2. 获取 Phoenix API 密钥

从右上角的用户菜单中获取 Phoenix API 密钥。点击 **API Key**，然后点击 API Key 进行复制：

<Frame>
  ![](https://i.ibb.co/pB1W0pk8/dify-docs-phoenix-api-key.png)
</Frame>

### 3. 集成 Phoenix 与 Dify

在 Dify 应用中配置 Phoenix。打开需要监控的应用，在侧边菜单中打开 **监控**，并在页面上选择 **追踪应用性能**。

<Frame>
  ![](https://i.ibb.co/gMmXxfhQ/dify-docs-phoenix-in-use.png)
</Frame>

点击配置后，输入 **项目** 名称；若启用了身份验证，还需填写 **API Key**。在 **Endpoint** 中填写 Phoenix 实例的基础 URL，然后保存。不要添加 `/v1/traces`，Dify 会自动补全数据接入路径。

<Frame>
  ![](https://i.ibb.co/jv6QFbp7/dify-docs-phoenix-config.png)
</Frame>

成功保存后，你可以在当前页面查看监控状态。

<Frame>
  ![](https://i.ibb.co/HTJsj9x2/dify-docs-phoenix-in-service.png)
</Frame>

### 配置 Phoenix Cloud

本章节将指引你注册 Phoenix Cloud 并将其集成至 Dify 平台内。

#### 1. 注册/登录 [Phoenix Cloud](https://app.arize.com/auth/phoenix/signup)

### 2. 创建你的 Phoenix 空间

你可以在右上角的用户菜单中创建 Phoenix 空间。点击 创建空间，然后为你的空间提供一个唯一的 URL 标识符：

<Frame>
  ![](https://i.ibb.co/7JYPzZBf/dify-docs-phoenix-cloud-create-space.png)
</Frame>

保存成功后，你可以在概览页面查看空间的状态。

<Frame>
  ![](https://i.ibb.co/Z6RqMhhq/dify-docs-phoenix-cloud-space-overview.png)
</Frame>

### 3. 创建你的 Phoenix API 密钥

启动空间后，你可以在左下角的用户菜单中点击 设置 来创建 Phoenix API 密钥。点击 系统密钥，然后为你的 API 密钥命名：

<Frame>
  ![](https://i.ibb.co/SXMyX9K3/dify-docs-phoenix-cloud-api-key.png)
</Frame>

### 4. 集成 Phoenix Cloud 与 Dify

在 Dify 应用中配置 Phoenix。打开需要监控的应用，在侧边菜单中打开 **监控**，并在页面上选择 **追踪应用性能**。

<Frame>
  ![](https://i.ibb.co/gMmXxfhQ/dify-docs-phoenix-in-use.png)
</Frame>

点击配置后，粘贴 **API Key** 和 **项目** 名称，并在 **Endpoint** 中填写完整的 Phoenix Cloud 空间 URL（例如 `https://app.phoenix.arize.com/s/<space>`），然后保存。

<Frame>
  ![](https://i.ibb.co/jv6QFbp7/dify-docs-phoenix-config.png)
</Frame>

成功保存后，你可以在当前页面查看监控状态。

<Frame>
  ![](https://i.ibb.co/HTJsj9x2/dify-docs-phoenix-in-service.png)
</Frame>

<Note>
保存配置并启用追踪后，重新运行应用，在监控服务中确认是否出现新的追踪记录。追踪数据会异步发送，仅保存配置不能确认追踪数据已送达。

对于 Agent 应用以及使用 [新版 Agent 节点](/zh/self-host/use-dify/nodes/agent#new-agent) 的工作流，需要在部署中同时启用 `OPS_AGENT_TRACE_ENABLED=true` 和 `DIFY_AGENT_APPLICATION_TRACING_ENABLED=true`。详见 [环境变量](/zh/self-host/deploy/configuration/environments#llmops-追踪投递)。这些应用的 **采集内容** 默认关闭，该设置控制整个工作流的输入和输出。其他应用仍可能发送输入和输出。
</Note>

## 监控数据列表

Dify 会按父子层级导出执行操作：消息包含 `llm` 调用，Chatflow 消息包含工作流及其节点操作。下表中的追踪 ID 和 span ID 由 Dify 派生生成，并非直接复制数据库 ID。只有模型调用会填充监控服务的原生 token 用量字段。

以下明细列出 Dify 的源记录和元数据。实际导出时仅发送相关且可用的值，不会完整发送原始记录。
