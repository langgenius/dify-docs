开发者可通过自定义端点扩展模块能力，当前支持以下模块扩展：

* `moderation` 敏感内容审核
* `external_data_tool` 外部数据工具

<Note>
如需用自有服务扫描上传至知识库的文件，在 **集成** > **文件安全扫描** 中将其添加为 **自定义端点** 扫描服务。该服务会收到的请求详见 [自定义端点扫描服务 API](/zh/self-host/use-dify/knowledge/file-security-scan-custom-endpoint)。
</Note>

扩展模块能力前，你需要准备一个 API，以及用于鉴权的 API 密钥。

除了需要开发对应的模块能力，还需要遵照以下规范，以便 Dify 正确调用 API。

## API 规范

Dify 按以下规范调用你的接口：

```
POST {Your-API-Endpoint}
```

### Header

| Header          | Value             | Desc                                                                  |
| --------------- | ----------------- | --------------------------------------------------------------------- |
| `Content-Type`  | application/json  | 请求内容为 JSON 格式。                                                        |
| `Authorization` | Bearer \{api_key\} | API 密钥以令牌形式传输。为保证接口安全，你需要解析出 `api_key`，核对它与所提供的 API 密钥是否一致。 |

### Request Body

```
{
    "point":  string, //  扩展点，不同模块可能包含多个扩展点
    "params": {
        ...  // 各模块扩展点传入参数
    }
}
```

### API 返回

```
{
    ...  // API 返回的内容，不同扩展点返回见不同模块的规范设计
}
```

## 校验

配置自定义端点时，Dify 会向 API Endpoint 发送一个请求，检验该 API 是否可用。

当 API Endpoint 接收到 `point=ping` 时，接口应返回 `result=pong`，具体如下：

### Header

```
Content-Type: application/json
Authorization: Bearer {api_key}
```

### Request Body

```
{
    "point": "ping"
}
```

### API 期望返回
```
{
    "result": "pong"
}
```

## 范例

此处以外部数据工具为例，场景为根据地区获取外部天气信息作为上下文。

### API 范例

POST https://fake-domain.com/api/dify/receive
```

**Header**

```

**Request Body**

{
    "point": "app.external_data_tool.query",
    "params": {

            "location": "London"

        "query": "How's the weather today?"
    }

```

**API 返回**

```
{
    "result": "City: London\nTemperature: 10°C\nRealFeel®: 8°C\nAir Quality: Poor\nWind Direction: ENE\nWind Speed: 8 km/h\nWind Gusts: 14 km/h\nPrecipitation: Light rain"
}
```

### 代码范例

代码基于 Python FastAPI 框架。

1.  安装依赖

    ```
    pip install fastapi[all] uvicorn
    ```
2.  按照接口规范编写代码

    ```
    from fastapi import FastAPI, Body, HTTPException, Header
    from pydantic import BaseModel

    app = FastAPI()


    class InputData(BaseModel):
        point: str
        params: dict = {}


    @app.post("/api/dify/receive")
    async def dify_receive(data: InputData = Body(...), authorization: str = Header(None)):
        """
        Receive API query data from Dify.
        """
        expected_api_key = "123456"  # TODO Your API key of this API
        auth_scheme, _, api_key = authorization.partition(' ')

        if auth_scheme.lower() != "bearer" or api_key != expected_api_key:
            raise HTTPException(status_code=401, detail="Unauthorized")

        point = data.point

        # for debug
        print(f"point: {point}")

        if point == "ping":
            return {
                "result": "pong"
            }
        if point == "app.external_data_tool.query":
            return handle_app_external_data_tool_query(params=data.params)
        # elif point == "{point name}":
            # TODO other point implementation here

        raise HTTPException(status_code=400, detail="Not implemented")


    def handle_app_external_data_tool_query(params: dict):
        app_id = params.get("app_id")
        tool_variable = params.get("tool_variable")
        inputs = params.get("inputs")
        query = params.get("query")

        # for debug
        print(f"app_id: {app_id}")
        print(f"tool_variable: {tool_variable}")
        print(f"inputs: {inputs}")
        print(f"query: {query}")

        # TODO your external data tool query implementation here, 
        #  return must be a dict with key "result", and the value is the query result
        if inputs.get("location") == "London":
            return {
                "result": "City: London\nTemperature: 10°C\nRealFeel®: 8°C\nAir Quality: Poor\nWind Direction: ENE\nWind "
                          "Speed: 8 km/h\nWind Gusts: 14 km/h\nPrecipitation: Light rain"
            }
        else:
            return {"result": "Unknown city"}
    ```
3.  启动 API 服务。默认端口为 8000，API 完整地址是 `http://127.0.0.1:8000/api/dify/receive`，配置的 API 密钥是 `123456`。

    ```
    uvicorn main:app --reload --host 0.0.0.0
    ```
4. 在 Dify 配置该 API。

5. 在应用中选择该自定义端点。

调试应用时，Dify 会请求已配置的 API，并发送以下内容（范例）：

```
{
    "point": "app.external_data_tool.query",
    "params": {
        "app_id": "61248ab4-1125-45be-ae32-0ce91334d021",
        "tool_variable": "weather_retrieve",
        "inputs": {
            "location": "London"
        },
        "query": "How's the weather today?"
    }
}
```

API 返回为：

}
```

## 本地调试

如果自定义端点运行在你的本机，而 Dify 部署在别处，可使用 [Ngrok](https://ngrok.com) 将本地端点暴露到公网，供 Dify 实例访问。操作步骤：

1.  进入 [https://ngrok.com](https://ngrok.com) 官网，注册并下载 Ngrok 文件。

    <Frame>
      ![下载](https://assets-docs.dify.ai/dify-enterprise-mintlify/zh_CN/guides/extension/api-based-extension/c44d6cc5425508daac8d31bc4af113df.png)
    </Frame>

2. 下载完成后，进入下载目录，根据下方说明解压压缩包，并执行说明中的初始化脚本。
    ```shell
    unzip /path/to/ngrok.zip
    ./ngrok config add-authtoken 你的 Token
    ```
3. 查看本地 API 服务的端口：

    <Frame>
      ![查看端口](https://assets-docs.dify.ai/dify-enterprise-mintlify/zh_CN/guides/extension/api-based-extension/7ac8ee0f0955f36255e0261b36499db7.png)
    </Frame>

    并运行以下命令启动：

        ```shell
        ./ngrok http 端口号
        ```

    启动成功的样例如下：

    <Frame>
      ![Ngrok 启动](https://assets-docs.dify.ai/dify-enterprise-mintlify/zh_CN/guides/extension/api-based-extension/2b4adbe0bb1ff203da521ea6eea401f8.png)
    </Frame>

4. 找到 Forwarding 一项对应的地址，即公网域名，如上图中的 `https://177e-159-223-41-52.ngrok-free.app`（此为示例域名，请替换为你自己的域名）。

沿用上面的范例：将本地已启动的服务端点暴露到公网后，把代码范例中的接口地址 `http://127.0.0.1:8000/api/dify/receive` 替换为 `https://177e-159-223-41-52.ngrok-free.app/api/dify/receive`。

此 API 端点即可通过公网访问。现在可在 Dify 中配置该 API 端点来调试本地代码。配置步骤参见 [外部数据工具](/zh/self-host/use-dify/workspace/api-extension/external-data-tool-api-extension)。
