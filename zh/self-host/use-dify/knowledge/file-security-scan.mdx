每个知识库都可在索引上传的文件之前，先扫描其中是否含有恶意软件。工作空间所有者或管理员先为工作空间接入一个或多个扫描服务，之后需要扫描的知识库即可各自开启。

扫描仅覆盖上传至知识库的文件，包括知识流水线中通过本地文件数据源上传的文件。来自 Notion、网页抓取、在线文档和在线网盘的内容不在扫描范围内，发送给应用、工作流或对话的文件也不会扫描。

<Note>
文件安全扫描默认关闭。将 `FILE_SCAN_ENABLED` 设为 `true` 即可启用。详见 [环境变量](/zh/self-host/deploy/configuration/environments#文件安全扫描)。
</Note>

## 接入扫描服务

在 **集成** > **文件安全扫描** 中点击 **添加扫描服务**，然后根据文件允许发往的范围，选择合适的类型：

- **Cloudmersive**、**Scanii** 或 **MetaDefender Cloud**：托管扫描服务，需要你在该服务开通账号。每个文件的内容都会发往该服务，每次扫描上传的文件都会占用你的账号额度。

  任何能编辑知识库设置的成员都可选用该扫描服务开启扫描，因此购买套餐时，应按所有可能用到它的知识库估算用量。

- **自定义端点**：公司自有的扫描服务。该服务需要处理的请求和响应格式详见 [自定义端点扫描服务 API](/zh/self-host/use-dify/knowledge/file-security-scan-custom-endpoint)。

  <Note>
  扫描服务位于公司内网时，需要先在部署环境中放行它的地址，Dify 才能访问到它。

  Dify 发出的请求都要经过代理。为防止有人借 Dify 访问你的内部系统，该代理默认拦截内网地址。设置以下任一变量即可放行你的端点：

  - `SSRF_PROXY_ALLOW_PRIVATE_IPS` = 端点的 IP 地址
  - `SSRF_PROXY_ALLOW_PRIVATE_DOMAINS` = 端点的主机名

  详见 [环境变量](/zh/self-host/deploy/configuration/environments#ssrf-代理)。
  </Note>

## 为知识库开启扫描

<Info>
开启扫描需要编辑者及以上角色。
</Info>

在知识库的 **设置** 中找到 **文件安全扫描**：开启扫描，选择 **扫描服务**，设置 [下面两个选项](#选择未扫描文件的处理方式)，最后点击 **保存**。

扫描对开启之后添加的文件生效。知识库中已有的文档会在下次处理时扫描，比如重试或分段设置变更时。如果检测到感染，该文档会显示 **错误**。

### 选择未扫描文件的处理方式

扫描在以下两种情况下无法给出结果，可分别选择拦截文件，或不经扫描直接放行：

- **扫描服务不可用时**：扫描服务无法连接、请求超时、返回服务器错误，或返回 Dify 无法解析的结果。遇到临时故障时，Dify 会先重试，之后才按此选项处理。
- **文件无法扫描时（已加密或过大）**：文件已加密或设有密码保护、超出扫描服务可接受的大小，或属于扫描服务不支持的类型。

仅当文件入库比逐个扫描更重要时，才将任一选项改为 **放行文件**。比如某个知识库在扫描服务停机期间也必须保持最新，或者经常要接收超出扫描服务大小上限的文件。这样放行的文件会跳过扫描直接索引，也没有任何标记表明它们未经扫描。

无论怎么选，Dify 始终会拦截检测出恶意软件的文件。扫描服务的凭据被拒绝或额度已用完时，发往该服务的文件也一样。

### 验证扫描是否生效

从 [eicar.org](https://www.eicar.org) 下载 EICAR 测试文件，上传到知识库。这个文件本身无害，但所有杀毒引擎都会把它识别为恶意软件。

对应的文档应显示 **错误**，并附带恶意软件相关的提示。如果文档照常完成了索引，检查该知识库是否已开启扫描并保存了设置。测试完成后可删除该测试文档。

## 处理被拦截的文件

在文档列表中，将鼠标悬停在文档 **错误** 状态旁的图标上，即可查看拦截原因。以下两种情况需要额外说明：

- **检测到恶意软件**：删除该文档。重试或重新上传同一文件，只会再次被拦截。
- **已加密、过大或扫描服务不支持**：这类文件默认会被拦截。如果可以接受它们不经扫描进入知识库，将该知识库的 **文件无法扫描时（已加密或过大）** 选项改为 **放行文件**，然后重试。

  该选项对知识库之后的所有文件都生效。如果只是为这一个文件临时放行，记得事后改回来。
