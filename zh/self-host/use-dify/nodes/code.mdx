## 配置

定义 **输入变量** 以访问工作流中其他节点的数据，然后在代码中引用这些变量。你的函数必须返回一个包含你已声明的 **输出变量** 的字典。

```python
def main(input_variable: str) -> dict:
    # Process the input
    result = input_variable.upper()
    return {
        'output_variable': result
    }
```

## 语言支持

根据你的需求和熟悉程度在 **Python** 和 **JavaScript** 之间进行选择。两种语言都在安全沙箱中运行，并可访问用于数据处理的常用库。

<Tabs>
  <Tab title="Python">
    Python 包含标准库，如 `json`、`math`、`datetime` 和 `re`。非常适合数据分析、数学运算和文本处理。
    
    ```python
    def main(data: list) -> dict:
        import json
        import math
        
        average = sum(data) / len(data)
        return {'result': math.ceil(average)}
    ```
  </Tab>
  
  <Tab title="JavaScript">
    JavaScript 提供标准内置对象和方法。适合 JSON 操作和字符串操作。
    
    ```javascript
    function main(data) {
        const processed = data.map(item => item.toUpperCase());
        return { result: processed };
    }
    ```
  </Tab>
</Tabs>

## 输出验证和限制

Dify 按部署中配置的限制，验证代码执行节点输出的字符串长度、数值范围与精度、数组大小和嵌套深度。

字符串输出中的 NUL 字符（`\u0000`）会被移除。

结果超出限制时，缩减输出，或联系部署管理员确认能否调整限制。

<Info>
运维人员可通过 `CODE_*` 设置调整输出限制。默认值和配置方法详见 [环境变量](/zh/self-host/deploy/configuration/environments#代码与模板输出限制)。
</Info>

## 安全考虑

只运行可信的代码：沙箱仍可连接部分其他 Dify 服务。如果必须阻止这些连接，运行代码前先联系部署管理员，配置 [额外的网络隔离](/zh/self-host/deploy/configuration/environments#沙箱服务)。

禁用沙箱网络后，沙箱服务会拒绝代码执行节点的执行请求，即使代码不发起网络调用也不例外。如果代码需要的网络访问受到部署限制，联系部署管理员。

## 依赖支持

代码节点支持 Python 和 JavaScript 的外部依赖：

```python
# Python: Import numpy, pandas, requests, etc.
import numpy as np
import pandas as pd

def main(data: list) -> dict:
    df = pd.DataFrame(data)
    return {'mean': float(np.mean(df['values']))}
```

```javascript
// JavaScript: Import lodash, moment, etc.
const _ = require('lodash');

function main(data) {
    return { unique: _.uniq(data) };
}
```

沙箱环境中预装了依赖项。可在你的 Dify 安装中查看可用包列表。
