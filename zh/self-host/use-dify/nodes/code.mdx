## 配置

定义 **输入变量** 以访问工作流中其他节点的数据，然后在代码中引用这些变量。你的函数必须返回一个包含你已声明的 **输出变量** 的字典。

```python
def main(input_variable: str) -> dict:
    # Process the input
    result = input_variable.upper()
    return {
        'output_variable': result
    }
```

## 语言支持

根据你的需求和熟悉程度在 **Python** 和 **JavaScript** 之间进行选择。两种语言都在安全沙箱中运行，并可访问用于数据处理的常用库。

<Tabs>
  <Tab title="Python">
    Python 包含标准库，如 `json`、`math`、`datetime` 和 `re`。非常适合数据分析、数学运算和文本处理。
    
    ```python
    def main(data: list) -> dict:
        import json
        import math
        
        average = sum(data) / len(data)
        return {'result': math.ceil(average)}
    ```
  </Tab>
  
  <Tab title="JavaScript">
    JavaScript 提供标准内置对象和方法。适合 JSON 操作和字符串操作。
    
    ```javascript
    function main(data) {
        const processed = data.map(item => item.toUpperCase());
        return { result: processed };
    }
    ```
  </Tab>
</Tabs>

## 输出限制

输出超出以下任一限制时，节点就会失败：

| 输出 | 默认限制 | 变量 |
|:--|:--|:--|
| 字符串长度 | 400,000 个字符 | `CODE_MAX_STRING_LENGTH` |
| 数值 | ±9,223,372,036,854,775,807 | `CODE_MAX_NUMBER`、`CODE_MIN_NUMBER` |
| 小数位数 | 20 | `CODE_MAX_PRECISION` |
| 对象嵌套深度 | 5 层 | `CODE_MAX_DEPTH` |
| `array[string]` 输出的元素数 | 30 | `CODE_MAX_STRING_ARRAY_LENGTH` |
| `array[object]` 输出的元素数 | 30 | `CODE_MAX_OBJECT_ARRAY_LENGTH` |
| `array[number]` 输出的元素数 | 1,000 | `CODE_MAX_NUMBER_ARRAY_LENGTH` |

默认设置下，`object` 输出中最多还能再嵌套 3 层对象：节点的输出整体算作第 1 层，数组不额外占一层。

结果超出限制时，缩减输出，或 [调高限制](/zh/self-host/deploy/configuration/environments#代码与模板输出限制)。

## 安全考虑

沙箱中的代码仍可访问 Dify 部署内的其他服务，因此只运行可信的代码。如需运行不可信的代码，先请部署管理员 [隔离沙箱网络](/zh/self-host/deploy/configuration/environments#沙箱服务)。

## 依赖支持

代码节点支持 Python 和 JavaScript 的外部依赖：

```python
# Python: Import numpy, pandas, requests, etc.
import numpy as np
import pandas as pd

def main(data: list) -> dict:
    df = pd.DataFrame(data)
    return {'mean': float(np.mean(df['values']))}
```

```javascript
// JavaScript: Import lodash, moment, etc.
const _ = require('lodash');

function main(data) {
    return { unique: _.uniq(data) };
}
```

沙箱环境中预装了依赖项。可在你的 Dify 安装中查看可用包列表。
