在 [创作者中心](https://creators.dify.ai/) 的 **插件** 页面查找和管理已发布插件。在 **消息** 中查看每一条评分、点赞和私密反馈。

## 查看已发布插件

切换至个人账户后，关联用于发布插件的 GitHub 账号。如果关联了多个账号，选择要查看其插件的账号。

每张插件卡都会显示下载量、总体评分、评分数量和点赞数。

## 与团队共同管理插件

选择团队使用的组织。该组织中列出的插件对所有组织成员可见。

如果要为插件创建新组织，请先在插件的市场详情页查找插件 ID，再将 `/` 前的部分填入 **唯一标识**。例如，插件 ID 为 `team-name/plugin-name` 时，输入 `team-name`。

<Frame caption="使用插件 ID 前缀作为唯一标识">
  ![使用插件 ID 前缀作为唯一标识](/images/develop-plugin/marketplace-organization-handle.svg)
</Frame>

组织创建完成后，插件会自动显示在该组织中。邀请团队成员后，他们无需关联自己的 GitHub 账号，也能查看相同插件。

### 认领未列出的插件

如果已发布的组织插件没有显示在创作者中心，可通过 **认领插件** 验证你有权管理该插件。提交插件 ID 和首次发布该插件的 PR，供审核使用。

1. 切换至个人账户，选择 **认领插件**。
2. 在市场详情页复制每个插件的插件 ID，并将其与首次发布该插件的 PR 配对。
3. 确认联系邮箱，并说明你在插件维护中的职责。如果 PR 由其他 GitHub 账号创建，说明原因。
4. 选择 **提交认领**。

在 **认领记录** 中跟踪请求。审核通过后，认领包含的插件会出现在你可管理的组织中。如果认领被拒绝，查看原因并选择 **新建认领**，更新证明材料后重新提交。
