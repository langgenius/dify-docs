## Web アプリから始める

共有への最速の道筋は Web アプリです。これらはアプリケーションを作成すると自動的に生成され、設定なしで即座に動作します。

<Steps>

    アプリで **公開する** をクリックして最新バージョンを有効化します。
  </Step>
  <Step title="URL をコピー">
    アプリの **アクセスポイント** タブで Web アプリのリンクを見つけます。
  </Step>
  <Step title="すぐに共有">
    ユーザーにリンクを送信します。必要に応じて、共有前に [アクセス元を許可したネットワークに制限](#ip-access-control) できます。
  </Step>
</Steps>

<Tip>
Web アプリはあらゆるデバイスで動作し、画面サイズに自動的に適応します。アプリストアの承認やインストールは不要です。
</Tip>

## 公開の仕組み

アプリを公開すると、Dify はすべてのチャネルにわたって最新の設定を有効化します。舞台裏で起こることは以下の通りです：

- **Web アプリ** は新機能と応答で即座に更新
- **API エンドポイント** は最新のモデルとワークフロー設定を提供
- **埋め込みウィジェット** は更新されたスタイルと動作を反映
- **MCP サーバー** は現在のアプリ機能へのアクセスを提供

<Warning>
公開すると、ライブアプリが現在の設定に置き換わります。ユーザーは次のインタラクションで即座に変更を確認できます。
</Warning>

## アクセス元を信頼できるネットワークに限定 <Badge color="blue">Professional</Badge> <Badge color="blue">Team</Badge> {#ip-access-control}

アプリのリンクが共有されても、オフィスのネットワークや指定したサーバーなど、信頼できるネットワークからのアクセスだけを許可できます。

アプリの **アクセスポイント** > **アクセス制御** で、IP アクセス制御を設定、管理できます。

<Info>
IP ポリシーを作成、編集、削除できるのは、ワークスペースのオーナーと管理者だけです。アプリのアクセスポイントを管理する権限を持つエディターは、既存のポリシーを使ってそのアプリのアクセス制御を設定できます。
</Info>

### アクセス制御の設定

1. **IP ポリシー** で既存のポリシーを選択します。同じポリシーをワークスペース内の複数のアプリで再利用できます。

    新しいポリシーを作成するには、**IP ポリシーを作成** をクリックします。

    **名前** を入力し、許可するアドレスを **許可リスト** に追加します。

    - 現在利用中のネットワークを許可するには、現在の IP アドレスの横にある **追加する** をクリックします。
    - 他のネットワークやシステムの担当者には、アプリへのアクセスに使うパブリック IP アドレスを確認してください。現在の自分の IP アドレスとは異なる場合があります。

    個別の IPv4 または IPv6 アドレスのほか、CIDR 表記でアドレス範囲を入力できます。範囲を追加すると、その範囲内のすべての IP アドレスからのリクエストが許可されます。

    **作成** をクリックし、**アクセス制御** で新しいポリシーを選択します。

2. **適用先** で、この IP ポリシーで保護するアクセスポイントをオンにし、**保存** をクリックします。選択しなかったアクセスポイントには、このポリシーによる制限は適用されません。

許可したネットワークと許可範囲外のネットワークの両方から、選択したアクセスポイントを通じてアプリにアクセスし、設定を確認してください。

### アクセス制御の管理

- **許可するアドレスの変更**：**編集** をクリックし、**IP ポリシー** の横にある **IP ポリシーを管理** アイコンをクリックします。ポリシーを選択し、**使用中のアプリ** を確認してください。変更は、このポリシーを使うすべてのアプリに影響します。**許可リスト** を更新し、**保存** をクリックします。変更は再公開せずに反映されます。

- **ポリシーや保護するアクセスポイントの変更**：**編集** をクリックし、選択を変更して **保存** をクリックします。アクセス制御が一時停止中の場合も、保存すると再び有効になります。

- **一時停止と再開**：**IP アドレスで制限** をオフにし、確認します。IP 制限は適用されなくなりますが、設定は保持されます。再開するには、もう一度オンにします。

- **ポリシーの削除**：**IP ポリシー** でポリシーの **…** メニューを開き、**削除** を選択します。削除は取り消せません。このポリシーを使うすべてのアプリから IP による保護が解除されます。

<Warning>
ワークスペースの Professional または Team のサブスクリプションが有効でなくなると、アプリの IP による保護が解除されます。IP ポリシーとアクセスポイントの選択は保持されます。IP による保護を再び利用するには、Professional または Team を更新するか、いずれかにアップグレードしてください。
</Warning>

## 公開のベストプラクティス

アプリを共有する前に、これらの設定を構成済みであることを確認してください：

- **アプリの説明** - ユーザーがアプリの機能を理解するのに役立つ
- **アイコンとブランディング** - アプリを認識しやすく専門的にする
- **アクセス制御** - アクセス元を許可したネットワークに制限するかを決定
- **レート制限** - アプリの過度な使用から保護（API アクセスでは特に重要）

<Check>
すべての公開方法は同じアプリ設定を使用します。一度設定すれば、どこでも公開できます。
</Check>
