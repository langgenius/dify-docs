アプリのリンクが共有されても、オフィスのネットワークや指定したサーバーなど、信頼できるネットワークからのアクセスだけを許可できます。

アプリにアクセスできるネットワークは、**IP ポリシー** に許可するパブリック IP アドレスを定義して制限できます。保護するアクセスポイントは **アクセス制御** で選べます。

<Info>
IP アクセス制御は Professional と Team プランで利用できます。

IP ポリシーを作成、編集、削除できるのは、ワークスペースのオーナーと管理者だけです。アプリのアクセスポイントを管理する権限を持つエディターは、既存のポリシーを使ってそのアプリのアクセス制御を設定できます。
</Info>

## IP ポリシーの管理

ワークスペースの **設定** > **IP ポリシー** で IP ポリシーを管理できます。同じポリシーを、そのワークスペース内の複数のアプリに適用できます。

### IP ポリシーの作成

**IP ポリシーを作成** をクリックします。ワークスペースに既存のポリシーがある場合は、**追加** をクリックします。**名前** を入力し、許可するアドレスを **許可リスト** に追加します。

- 現在利用中のネットワークを許可するには、現在の IP アドレスの横にある **追加する** をクリックします。
- アプリにアクセスするネットワークやシステムの担当者に、パブリック IP アドレスを確認します。

個別の IPv4 または IPv6 アドレスのほか、CIDR 表記でアドレス範囲を入力できます。範囲を追加すると、その範囲内のすべての IP アドレスからのリクエストが許可されます。

**作成** をクリックします。その後、アプリの **アクセス制御** 設定で [ポリシーを適用](#アプリのアクセス制御の設定) できます。

### IP ポリシーの編集 {#change-allowed-ip-addresses}

<a id="更改允许的-ip-地址"></a>
<a id="許可する-ip-アドレスの変更"></a>

**IP ポリシー** でポリシーを選択し、**許可リスト** を更新して **保存** をクリックします。

変更は、このポリシーを使うすべてのアプリに影響し、再公開せずに反映されます。

### IP ポリシーの削除

削除は取り消せません。このポリシーを使うすべてのアプリから IP による保護が解除されます。

**IP ポリシー** でポリシーの **…** メニューを開き、**削除** を選択して確定します。

## アプリのアクセス制御の設定

**スタジオ** からアプリを、Agent の場合は **Agents** から開き、**アクセスポイント** タブに移動します。右上に **アクセス制御** があります。

### アクセス制御の設定

1. **IP ポリシー** で使用するポリシーを選択します。
2. **適用先** で、この IP ポリシーで保護するアクセスポイントをオンにし、**保存** をクリックします。選択しなかったアクセスポイントには、このポリシーによる制限は適用されません。

設定を確認するには、許可したネットワークと許可範囲外のネットワークから、選択したアクセスポイントをテストしてください。

### ポリシーや保護するアクセスポイントの変更

**アクセス制御** で **編集** をクリックします。**IP ポリシー** または **適用先** の選択を変更して **保存** をクリックします。

アクセス制御が一時停止中の場合も、保存すると再び有効になります。

### アクセス制御の一時停止と再開

**アクセス制御** で **IP アドレスで制限** をオフにし、確認します。再開するには、もう一度オンにします。

一時停止中は IP 制限が適用されなくなりますが、設定は保持されます。

<Warning>
Professional または Team のサブスクリプションが無効になった場合も、IP による保護が解除されます。設定は保持されます。IP による保護を再び利用するには、いずれかのプランを更新するか、アップグレードしてください。
</Warning>
