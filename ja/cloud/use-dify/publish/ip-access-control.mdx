アプリのリンクが共有されても、オフィスのネットワークや指定したサーバーなど、信頼できるネットワークからのアクセスだけを許可できます。

アプリの **アクセスポイント** > **アクセス制御** で、IP アクセス制御を設定、管理できます。

<Info>
IP アクセス制御は Professional と Team プランで利用できます。

IP ポリシーを作成、編集、削除できるのは、ワークスペースのオーナーと管理者だけです。アプリのアクセスポイントを管理する権限を持つエディターは、既存のポリシーを使ってそのアプリのアクセス制御を設定できます。
</Info>

## アクセス制御の設定

1. **IP ポリシー** で既存のポリシーを選択するか、**IP ポリシーを作成** をクリックします。同じポリシーをワークスペース内の複数のアプリで再利用できます。

    新しいポリシーを作成する場合は、**名前** を入力し、許可するアドレスを **許可リスト** に追加します。

    - 現在利用中のネットワークを許可するには、現在の IP アドレスの横にある **追加する** をクリックします。
    - アプリにアクセスするネットワークやシステムの担当者に、パブリック IP アドレスを確認してください。

    個別の IPv4 または IPv6 アドレスのほか、CIDR 表記でアドレス範囲を入力できます。範囲を追加すると、その範囲内のすべての IP アドレスからのリクエストが許可されます。

    **作成** をクリックし、**アクセス制御** で新しいポリシーを選択します。

2. **適用先** で、この IP ポリシーで保護するアクセスポイントをオンにし、**保存** をクリックします。選択しなかったアクセスポイントには、このポリシーによる制限は適用されません。

許可したネットワークと許可範囲外のネットワークの両方から、選択したアクセスポイントを通じてアプリにアクセスし、設定を確認してください。

## 許可する IP アドレスの変更

**編集** をクリックし、**IP ポリシー** の横にある **IP ポリシーを管理** アイコンをクリックします。**IP ポリシー** でポリシーを選択し、**許可リスト** を更新して **保存** をクリックします。

変更は、このポリシーを使うすべてのアプリに影響し、再公開せずに反映されます。

## ポリシーや保護するアクセスポイントの変更

**編集** をクリックし、**IP ポリシー** または **適用先** の選択を変更して **保存** をクリックします。

アクセス制御が一時停止中の場合も、保存すると再び有効になります。

## アクセス制御の一時停止と再開

**IP アドレスで制限** をオフにし、確認します。再開するには、もう一度オンにします。

一時停止中は IP 制限が適用されなくなりますが、設定は保持されます。

<Warning>
ワークスペースの Professional または Team のサブスクリプションが有効でなくなると、アプリの IP による保護が解除されます。ただし、IP ポリシーとアクセスポイントの選択は保持されます。IP による保護を再び利用するには、Professional または Team を更新するか、いずれかにアップグレードしてください。
</Warning>

## IP ポリシーの削除

**IP ポリシー** でポリシーの **…** メニューを開き、**削除** を選択します。

削除は取り消せません。このポリシーを使うすべてのアプリから IP による保護が解除されます。
