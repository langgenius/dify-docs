ナレッジベース内の左サイドバーにある **検索テスト** アイコンをクリックして、テストページに移動します。

このページでは、ユーザーのクエリをシミュレートして、ナレッジベースがどの程度関連情報を正しく検索できるかを確認し、最適なパフォーマンスを得るためにさまざまな [検索設定](/ja/cloud/use-dify/knowledge/create-knowledge/setting-indexing-methods#検索設定の指定) を試すことができます。

<Note>
    ここで調整した検索設定は一時的なもので、現在のテストセッションにのみ適用されます。
</Note>

<Tip>
多数の質問で検索の品質をまとめて採点するには、[評価を実行](/ja/cloud/use-dify/evaluate/run-evaluations) します。
</Tip>

**記録** セクションには、このナレッジベースに関連するすべての検索イベントが記録されます。これには以下が含まれます。

- **検索テスト** ページ上で直接実行したクエリ
- リンクされたアプリからの検索要求（テスト運用中または本番環境を問わず）

<Info>
    テスト検索と通常の検索は同じ API エンドポイントを使用します。
</Info>
