ナレッジベースごとに、アップロードされたファイルにマルウェアが含まれていないか、インデックス化の前にスキャンできます。まず、ワークスペースのオーナーまたは管理者が、スキャナーを 1 つ以上接続します。スキャナーが接続されると、各ナレッジベースで必要に応じてスキャンを有効にできるようになります。

スキャンの対象は、従来型ナレッジベースと Agent ナレッジベースにアップロードされたファイルだけです。ナレッジパイプラインでローカルファイルのデータソースから取り込んだファイルも含まれます。ナレッジベースが Notion、ウェブサイトのクロール、オンラインドキュメント、オンラインドライブから取り込んだコンテンツはスキャンされません。アプリ、ワークフロー、チャットに送信されたファイルも対象外です。

## スキャナーの接続

**連携** > **ファイルセキュリティスキャン** で **スキャナーを追加** をクリックし、ファイルを送信してよい範囲に合わせて種類を選択します。

- **Cloudmersive**、**Scanii**、または **MetaDefender Cloud**：自社のアカウントで使うホスト型サービスです。各ファイルの内容はそのサービスに送信されます。

  スキャンするファイルごとに、そのサービスのクォータを消費します。また、ナレッジベースの設定を編集できるメンバーなら誰でも、このスキャナーでスキャンを有効にできます。そのため、使う可能性のあるナレッジベースすべての利用量を見込んで、プランを選んでください。

- **カスタム API**：自社のスキャンサービスです。

  インターネットから到達できる必要があるため、社内ネットワーク上でのみ動作しているサービスには、先にパブリックアドレスを用意してください。サービスが処理する必要のあるリクエストとレスポンスについては、[カスタム API スキャナーの仕様](/ja/cloud/use-dify/knowledge/file-security-scan-custom-endpoint) を参照してください。

Dify はスキャナーの保存時に接続をテストし、テストに失敗したスキャナーは保存しません。

## ナレッジベースでのスキャンの有効化

ナレッジベースの **設定** で、**ファイルセキュリティスキャン** セクションに移動します。スキャンを有効にして **スキャナー** を選択し、[後述の 2 つの設定](#スキャンで判定できないファイルの扱い) を行います。最後に変更を保存します。

スキャンは、有効にした後にアップロードしたファイルに適用されます。すべてのファイルをスキャンするには、まず空のナレッジベースを作成してスキャンを有効にし、それからファイルをアップロードしてください。

ナレッジベースにすでにあるドキュメントの扱いは、ナレッジベースの種類によって異なります。

- **従来型ナレッジベース**：再試行したときやチャンク設定を変更したときなど、ドキュメントが次に処理される際にスキャンされます。感染していることがわかると、そのドキュメントには **エラー** と表示されます。
- **Agent ナレッジベース**：再試行や再インデックス化を行っても、既存のドキュメントは一切スキャンされません。

既存のドキュメントをすぐにスキャンしたい場合は、そのドキュメントを削除して、ファイルを再度アップロードしてください。

### スキャンで判定できないファイルの扱い

スキャンで判定できないケースは 2 つあります。それぞれについて、ファイルをブロックするか、スキャンせずに受け入れるかを選択します。

- **スキャナーが利用できない場合**：スキャナーに接続できない、タイムアウトする、サーバーエラーを返す、または Dify が解釈できない応答を返す場合です。
- **ファイルをスキャンできない場合（暗号化されている、またはサイズが大きすぎる）**：ファイルが暗号化またはパスワードで保護されている場合です。スキャナーが受け付けるサイズを超えている場合や、スキャナーが対応していない形式の場合も含みます。

どちらの設定も、**ファイルを許可** に切り替えるのは、全ファイルのスキャンよりもファイルの取り込みを優先したい場合に限ってください。スキャナーの停止中も最新の状態を保つ必要があるナレッジベースや、スキャナーの上限サイズを超えるファイルを日常的に扱うナレッジベースなどが該当します。この方法で許可されたファイルはスキャンされずにインデックス化され、未スキャンであることを示す表示もありません。

どちらを選んでも、マルウェアが検出されたファイルは必ずブロックされます。認証情報が拒否されたスキャナーや、クォータを使い切ったスキャナーに送られたファイルも同様です。

### スキャンの動作確認

[eicar.org](https://www.eicar.org) から EICAR テストファイルをダウンロードします。EICAR テストファイルは無害なファイルですが、どのウイルス対策エンジンもマルウェアとして検出します。拡張子を `.txt` にして保存し、ナレッジベースにアップロードします。ファイルはブロックされ、マルウェアが検出されたことを示すメッセージが表示されるはずです。

インデックス化されてしまった場合：

- ファイルをアップロードする前に、スキャンを有効にして設定を保存していたかを確認します。
- ナレッジベースの **スキャナーが利用できない場合** の設定を確認します。**ファイルを許可** を選んでいると、スキャナーが応答しないときに、ファイルがスキャンされずに取り込まれます。スキャナーが応答するかどうかは、ワークスペースのオーナーまたは管理者が確認できます。**連携** > **ファイルセキュリティスキャン** で、そのスキャナーの **テスト** をクリックしてください。

## ブロックされたファイルへの対処

ファイル自体が原因でブロックされた場合は、その理由に応じて対処します。

- **マルウェアが検出された**：このファイルはナレッジベースに追加しないでください。再試行しても、同じファイルを再度アップロードしても、またブロックされるだけです。

- **暗号化されている、サイズが大きすぎる、またはスキャナーが対応していない**：このようなファイルは、デフォルトでブロックされます。スキャンせずにナレッジベースに取り込んでもかまわない場合は、次の手順に従います。

  1. **ファイルをスキャンできない場合（暗号化されている、またはサイズが大きすぎる）** を **ファイルを許可** に切り替えて保存します。
  2. 従来型ナレッジベースでは、ドキュメントを再試行します。Agent ナレッジベースでは、ファイルを削除してから再度アップロードします。
  3. このファイルのためだけに設定を変更した場合は、ファイルが取り込まれた後に元に戻します。戻さない限り、この設定は以降そのナレッジベースに追加されるすべてのファイルに適用されます。
