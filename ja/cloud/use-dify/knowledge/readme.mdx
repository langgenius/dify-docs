従来型ナレッジベースでは、コンテンツのチャンキング、インデックス作成、検索の方法を自分で決めます。すでに運用しているナレッジベースに接続することもできます。その場合、Dify はコンテンツを取り込まずに直接検索します。

チャットボット、テキストジェネレーター、レガシー Agent の各アプリは、従来型ナレッジベースをもとに回答できます。Workflow アプリと Chatflow アプリでも、知識検索ノードを通じて利用できます。

<Tip>

- Agent ナレッジベースとどちらが適しているかは、[作成する種類の選び方](/ja/cloud/use-dify/knowledge/overview#choose) を参照してください。

- すぐに使える従来型ナレッジベースは、Agent ナレッジベースに [アップグレード](/ja/cloud/use-dify/knowledge-base/upgrade-from-classic) できます。外部ナレッジベースと、ナレッジパイプラインとして構築したナレッジベースはアップグレードできません。

</Tip>

## セットアップ {#set-up}

- **[すぐに使えるナレッジベースを作成](/ja/cloud/use-dify/knowledge/create-knowledge/introduction)**：データをインポートし、チャンキング、インデックス作成、検索の方法を設定します。

- **[カスタムナレッジベースを構築](/ja/cloud/use-dify/knowledge/knowledge-pipeline/readme)**：標準の設定がコンテンツに合わない場合に、処理の流れをナレッジパイプラインとして独自に設計します。データソースと、抽出、チャンキング、インデックス作成の各ステップを自分で選べます。

- **[外部ナレッジベースと連携](/ja/cloud/use-dify/knowledge/connect-external-knowledge-base)**：すでに運用しているナレッジベースを API 経由で検索します。コンテンツを Dify に移す必要はありません。

## テストと改善

- **[検索検証](/ja/cloud/use-dify/knowledge/test-retrieval)**：ユーザーが尋ねそうな質問を試し、どのチャンクが返されるかを確認します。

- **[ナレッジベース設定の調整](/ja/cloud/use-dify/knowledge/manage-knowledge/introduction)**：埋め込みモデルと検索設定を変更します。インデックス方法を「経済的」から「高品質」に切り替えることもできます。

- **[メタデータによる検索強化](/ja/cloud/use-dify/knowledge/metadata)**：ドキュメントにラベルを付け、条件に合うドキュメントだけに検索を絞り込めるようにします。

## 利用とメンテナンス

- **[アプリケーションへの統合](/ja/cloud/use-dify/knowledge/integrate-knowledge-within-application)**：アプリに接続し、アプリからの検索方法を設定します。

- **[コンテンツ管理](/ja/cloud/use-dify/knowledge/manage-knowledge/maintain-knowledge-documents)**：コンテンツの変化に合わせて、ドキュメントやチャンクを追加、編集、無効化、削除します。
