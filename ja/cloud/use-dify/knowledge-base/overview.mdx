Agent ナレッジベースは、コンテンツの処理を代わりに引き受けます。推論モデルが各ドキュメントを読んで整理し、埋め込みモデルが検索できる形にします。手作業はわずかで、入れるコンテンツを選び、検索の深度を設定し、返ってくる結果を確認するだけです。

デフォルトの深度では、意味とキーワードで照合して検索します。[検索の深度](/ja/cloud/use-dify/knowledge-base/retrieval-settings#retrieval-depth) を深くすると、ナレッジベースはエージェントのように質問を調べます。ドキュメントをまたいで関連する主題をたどったり、質問を複数に分解してセクション全体を読んだりします。

アプリだけでなく、手元のマシンで動くコーディングエージェントも、[Dify CLI](/ja/cloud/use-dify/knowledge-base/use-knowledge-in-apps#from-your-coding-agent) を通じてドキュメントを読み取れます。フォルダ内のファイルと同じ感覚で閲覧できます。

<Tip>

- 従来型ナレッジベースとどちらが適しているかは、[作成する種類の選び方](/ja/cloud/use-dify/knowledge/overview#choose) を参照してください。

- 既存の従来型ナレッジベースを移行するには、[アップグレードの手順](/ja/cloud/use-dify/knowledge-base/upgrade-from-classic) を参照してください。

</Tip>

- **[インデックス済みドキュメントの確認](/ja/cloud/use-dify/knowledge-base/review-indexed-documents)**：ドキュメントがどのように分割、要約されたかを確認し、うまく取り込まれなかった部分を修正します。

- **[画像検索の設定](/ja/cloud/use-dify/knowledge-base/multimodal-retrieval)**：画像を検索で扱えるようにするモデルを選びます。
