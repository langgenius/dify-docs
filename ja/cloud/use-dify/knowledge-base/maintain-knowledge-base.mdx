アプリがナレッジベースを利用し始めたら、ときどき **概要** ページを確認し、示された問題を修正してください。

## 「概要」ページの確認

### 注意が必要な項目

- **ソースデータが古くなっています**：ソースが一度も同期に成功していないか、最後に同期に成功してから 7 日を超えています。

    **ソース** ページで **今すぐ同期** をクリックします。ソースに **エラー** と表示されている場合は、示された原因を先に解消してから **再試行** をクリックします。

- **ドキュメントの処理に失敗しました**：ドキュメントの最新バージョンをインデックスできませんでした。以前のバージョンがインデックス済みであれば、更新が成功するまで、検索ではそのバージョンが使われます。

    **ドキュメント** ページでステータスにカーソルを合わせて理由を確認し、**再試行** をクリックします。原因がコンテンツ自体にある場合は、ソース側で修正してから再度同期します。アップロードしたファイルの場合は、[ドキュメントの更新](#ドキュメントの更新) を参照してください。

- **クエリ品質の確認が必要です**：検索テストまたはサービス API で送られた質問で、返ってきた根拠が弱いか、根拠が見つかりませんでした。

    **検索テスト** ページで同じ質問を再実行します。それでも適切な結果が得られない場合は、[問題ケースとして保存](/ja/cloud/use-dify/knowledge-base/test-and-tune#問題ケース) し、改善に取り組みます。

- **モデル設定が未完了です**：必要なモデルが設定されていないか、ドキュメントがまだ 1 つもインデックスされていないため、モデルを検証できていません。

    不足しているモデルは **設定** > **検索** で設定します。ナレッジベースがまだ空の場合は、ドキュメントを追加します。

### クエリの結果

検索がユーザーの期待に応えられなかった頻度は、**クエリの結果** グラフで確認できます。選択した期間のすべての質問が対象で、検索テスト、アプリ、API の呼び出し元のどこから届いたかは問いません。各質問は、検索で何が見つかったかによって分類されます。

- **根拠なし**：何も返されなかった質問です。

- **低信頼度**：チャンクは返されたものの、すべてがしきい値を下回った質問です。**スコア閾値** がオンの場合にのみ表示されます。

- **回答済み**：上記以外のすべての質問です。

**低信頼度** や **根拠なし** が増えてきたら、ユーザーが実際に尋ねる質問を使って [検索のテストとチューニング](/ja/cloud/use-dify/knowledge-base/test-and-tune) を行います。

## ソースの同期と管理

次のスケジュール実行まで待てない場合は、**ソース** ページでソースのメニューを開き、**今すぐ同期** をクリックします。

ソースにページやファイルを追加するには、ソースを編集して選択内容を更新します。

ソースを削除しても、そのドキュメントは削除されません。ドキュメントはナレッジベースに残りますが、更新されなくなります。内容が不要になった場合は、ドキュメントを別途削除してください。

## ドキュメントの更新

アップロードしたファイルを更新するには、古いドキュメントを削除してから新しいバージョンをアップロードします。同じ名前のファイルをアップロードすると、既存のドキュメントは置き換えられず、2 つ目のドキュメントとして追加されます。

内容が一時的に古くなっているだけなら、ドキュメントを削除せずに無効にします。無効にしたドキュメントは、再び有効にするまで検索の対象から外れます。
