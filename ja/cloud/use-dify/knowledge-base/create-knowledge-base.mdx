**ナレッジ** を開き、**Agent** に切り替えて、**作成** をクリックします。

## 基本情報の設定

ナレッジベースに名前と説明を付け、閲覧したり自分のアプリに接続したりできるメンバーを設定します。これらはすべて、後からナレッジベースの設定で変更できます。

ナレッジベースには、ワークスペースのデフォルトのモデルが使われます。ドキュメント内の画像を検索できるようにするには、[ビジョン対応の埋め込みモデル](/ja/cloud/use-dify/knowledge-base/multimodal-retrieval) が必要です。コンテンツを追加した後でこのモデルに切り替えると、すべてのドキュメントのインデックスが再作成されます。

## コンテンツの追加

コンテンツが別の場所にあって随時更新される場合は、ソースを接続します。単体のドキュメントであれば、ファイルをアップロードします。1 つのナレッジベースに両方を混在させることもできます。

<Tip>
まずは代表的なドキュメントを少しだけ追加し、検索のチューニングが済んでから残りをインポートしてください。後から埋め込みモデルや推論モデルを変更すると、すべてのドキュメントのインデックスが再作成されます。ナレッジベースが小さいうちなら、消費するトークンも少なく済みます。
</Tip>

### ソースの接続 {#connect-a-source}

ソースは、ウェブサイト、ドキュメントプラットフォーム、クラウドドライブからコンテンツを取り込みます。取り込みには、Firecrawl、Notion、Google Drive などのデータソース連携を使います。

<Steps>
  <Step title="プロバイダーの選択">
    ワークスペースにインストール済みのデータソース連携から選択します。**その他のプロバイダー** をクリックして、新しく探してインストールすることもできます。

    <Tip>
    必要な連携が見つからない場合は、[自分で開発する](/ja/develop-plugin/dev-guides-and-walkthroughs/datasource-plugin) か、コミュニティに [リクエスト](https://github.com/langgenius/dify-plugins/issues/new?template=plugin_request.yaml) してください。
    </Tip>

    **連携** > **データソース** で API キーを入力するか、アカウントを認可して、接続を設定します。

  </Step>
  <Step title="同期する内容の選択">
    <Tabs>
      <Tab title="ウェブサイトのクロール">
        1. ソースに名前を付けて URL を貼り付けます。続いて **クロールオプション** でクロールのデフォルト設定を確認し、必要に応じて調整します。

        2. **クロールしてプレビュー** をクリックし、結果からインポートするページを選択します。
      </Tab>
      <Tab title="オンラインドキュメント">
        接続したアカウントから、インポートするページを選択します。
      </Tab>
      <Tab title="オンラインドライブ">
        接続したドライブまたはバケットから、インポートするファイルを選択します。
      </Tab>
    </Tabs>
  </Step>
  <Step title="同期ポリシーの設定">
    プリセットのスケジュールを選ぶか、カスタム間隔（1 時間から 30 日まで）を設定します。手動同期に切り替えることもできます。

    コンテンツの更新頻度に合わせて設定してください。同期で変更が見つかると、その部分のインデックスが再作成され、トークンを消費します。
  </Step>
</Steps>

### ファイルのアップロード

1 ファイルあたりの上限は 15 MB です。

<Tip>
一括アップロードは <Badge color="blue" size="sm">Professional</Badge> と <Badge color="blue" size="sm">Team</Badge> で利用できます。詳しくは [料金ページ](https://dify.ai/pricing) を参照してください。
</Tip>

## 次のステップ

**ドキュメント** ページでドキュメントが **準備完了** になったら、実際のユーザーに使ってもらう前に、次の 3 つのステップを行います。

1. [インデックス済みドキュメントの確認](/ja/cloud/use-dify/knowledge-base/review-indexed-documents)：ドキュメントを開き、セクション、要約、チャンクが適切に生成されているかを確認します。

2. [検索のテストと設定のチューニング](/ja/cloud/use-dify/knowledge-base/test-and-tune)：アプリが実際に受ける質問を試し、安定して正しい結果が返るようになるまで調整します。

3. [アプリ、Agent、コードへの接続](/ja/cloud/use-dify/knowledge-base/use-knowledge-in-apps)：このナレッジベースをもとに回答させたいアプリに接続します。
