ダッシュボードは、アプリケーションのパフォーマンスを示すために、時間の経過に伴う 4 つの指標を追跡します：

<Frame>
  ![モニタリングダッシュボード](/images/use-dify/monitor/monitoring-dashboard.png)
</Frame>

**Total Messages**：会話のボリューム  
**Active Users**：意味のあるインタラクションを持つユーザー（複数のやり取りがある）  
**Average User Interactions**：セッションごとのエンゲージメントの深さ  
**Token Usage**：リソース消費とコスト

時間セレクターを使用して、異なる期間のトレンドを確認します。**「アプリのパフォーマンスのトレース」** をクリックして、[Langfuse](/ja/cloud/use-dify/monitor/integrations/integrate-langfuse) や [LangSmith](/ja/cloud/use-dify/monitor/integrations/integrate-langsmith) などの外部可観測性プラットフォームに接続し、より深い分析を行います。

[Agent](/ja/cloud/use-dify/build/new-agent/overview) の場合は、Agent の **モニタリング** セクションから同じトレース設定を開きます。この設定が適用されるのは、チャット、Web アプリ、API 呼び出しなど、Agent 自身の実行です。Agent が Workflow または Chatflow 内で実行される場合は、そのアプリのトレース設定が適用されます。

トレース設定の **Agent データ収集** で、トレースに含める内容を設定します。対象は Agent アプリと、[新しい Agent ノード](/ja/cloud/use-dify/nodes/agent#new-agent) を含むワークフローです。

- **Agent の内部処理を収集**：Agent のモデル呼び出しとツール呼び出しです。これらのステップをトレースプロバイダーに送りたくない場合はオフにします。オフにすると、トレース上の Agent は 1 つのステップとして表示されます。
- **内容を収集**：Agent だけでなく、トレース内のすべてのステップの入力と出力です。オンにすると、プロンプト、ユーザーメッセージ、応答がトレースプロバイダーに送信されます。

それ以外のワークフロー（クラシック Agent ノードしかないものを含む）では、これらのスイッチを設定しても効果はありません。
