ダッシュボードは、アプリケーションのパフォーマンスを示すために、時間の経過に伴う 4 つの指標を追跡します：

<Frame>
  ![モニタリングダッシュボード](/images/use-dify/monitor/monitoring-dashboard.png)
</Frame>

**Total Messages**：会話のボリューム  
**Active Users**：意味のあるインタラクションを持つユーザー（複数のやり取りがある）  
**Average User Interactions**：セッションごとのエンゲージメントの深さ  
**Token Usage**：リソース消費とコスト

時間セレクターを使用して、異なる期間のトレンドを確認します。**「アプリのパフォーマンスのトレース」** をクリックして、Langfuse や LangSmith などの外部可観測性プラットフォームに接続し、より深い分析を行います。

Agent の場合は、Agent の **モニタリング** セクションから同じトレース設定を開きます。

**Agent データ収集** の **内容を収集** をオンにすると、トレースに入力と出力が含まれます。対象は Agent アプリと、Agent ノードを含むワークフローです。この設定は Agent だけでなく、トレース内のすべてのノードに適用されます。

<Note>
Agent トレースはデフォルトで無効です。次の変数を設定して有効にします：

- `OPS_AGENT_TRACE_ENABLED` = `true`
- `DIFY_AGENT_APPLICATION_TRACING_ENABLED` = `true`

詳細は [環境変数](/ja/self-host/deploy/configuration/environments#llmops-トレース配信) を参照してください。
</Note>
