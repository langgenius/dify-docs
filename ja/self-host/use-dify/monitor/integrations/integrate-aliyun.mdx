## Alibaba Cloud Monitor とは

Alibaba Cloud は、Dify アプリケーションのワンクリック監視、トレース、評価を可能にする、フルマネージドかつメンテナンス不要のオブザーバビリティプラットフォームを提供します。

<Info>
  Alibaba Cloud Monitor は、[LoongSuite](https://github.com/alibaba/loongsuite-python-agent) エージェントやオープンソースの OpenTelemetry エージェントを通じて、Python/Golang/Java アプリケーションをネイティブにサポートします。Dify LLM アプリケーションのワンクリック監視に加え、非侵入型エージェントによる Dify コンポーネントおよびその上下流依存関係のエンドツーエンドの可観測性もサポートします。
  
  詳細は [Cloud Monitor ドキュメント](https://www.alibabacloud.com/help/en/cms/cloudmonitor-1-0/product-overview/what-is-cloudmonitor?spm=a3c0i.63551.2277339270.1.76c7112eeKEvSr) をご参照ください。
</Info>

## Alibaba Cloud Monitor の設定方法

### 1. Alibaba Cloud のエンドポイントとライセンスキーの取得

1. [ARMS コンソール](https://account.alibabacloud.com/login/login.htm?spm=5176.12901015-2.0.0.68d74b84XRatpU)にログインし、左側のナビゲーションバーで **Integration Center** をクリックします。
2. **Server-side Applications** エリアで **OpenTelemetry** カードをクリックします。
3. 表示された **OpenTelemetry** パネルで、エクスポートプロトコルとして **HTTP** を選択します。実際のデプロイに応じて接続方法とリージョンを選択します。

<Frame>
  ![Alibaba Cloud アクセスポイントの取得](https://dify-public-resources.oss-cn-hangzhou.aliyuncs.com/dify-doc/get_endpoint.png)
</Frame>

4. **Public Endpoint** と **Authentication Token (License Key)** を保存します。

<Note>
  **Endpoint** には HTTP(S) のベース URL を指定します。HTTP コレクターにポート指定が必要な場合は、そのポートを残してください。トークンは **License Key** に別途入力します。`adapt_<key>` や取り込みパスを含めず、gRPC ポートの `8090` は使用しないでください。OTLP/HTTP の取り込み URL は Dify が組み立てます。
</Note>

### 2. Dify で Cloud Monitor を設定

<Info>
  Dify v1.6.0 以上が必要です。
</Info>

1. Dify コンソールにログインし、監視したいアプリケーションに移動します。
2. 左側のナビゲーションバーで **Monitoring** を開きます。
3. **Tracing app performance** をクリックし、**Cloud Monitor** エリアで **Configure** をクリックします。

<Frame>
  ![Alibaba Cloud Monitor の設定](https://dify-public-resources.oss-cn-hangzhou.aliyuncs.com/dify-doc/config_cms.png)
</Frame>

4. 表示されたダイアログで、手順 1 で取得した **License Key** と **Endpoint** を入力し、**App Name**（ARMS コンソールに表示されるアプリケーション名）をカスタマイズして **Save & Enable** をクリックします。

## Alibaba Cloud Monitor での監視データの表示

設定後、Dify のアプリケーションからのデバッグまたは本番データは Cloud Monitor で監視できます。

### 方法 1: Dify アプリケーションから ARMS コンソールにジャンプ

Dify コンソールでトレースが有効になっているアプリケーションを選択し、**Tracing Configuration** に移動して、**Cloud Monitor** エリアの **View** をクリックします。

### 方法 2: ARMS コンソールで直接表示

ARMS コンソールの **LLM Application Monitoring > Application List** ページで、対応する Dify アプリケーションに移動します。

## より多くのデータにアクセス

Cloud Monitor は、Dify クラスターのさまざまなコンポーネントにアクセスしてエンドツーエンドのトレースを実現するマルチランゲージの非侵入型エージェントを提供します。

| Dify コンポーネント | エージェント | 詳細 |
|----------------|-------|---------|
| Nginx | OpenTelemetry Agent | [Nginx トレースに OpenTelemetry を使用](https://www.alibabacloud.com/help/en/opentelemetry/user-guide/use-opentelemetry-to-perform-tracing-analysis-on-nginx?spm=a2c63.l28256.help-menu-search-90275.d_1) |
| API | LoongSuite-Python Agent | [loongsuite-python-agent](https://github.com/alibaba/loongsuite-python-agent/blob/main/README.md) |
| Sandbox | LoongSuite-Go Agent | [loongsuite-go-agent](https://github.com/alibaba/loongsuite-go-agent/blob/main/README.md) |
| Worker | OpenTelemetry Agent | [OpenTelemetry を介して Python アプリケーションデータを送信](https://www.alibabacloud.com/help/en/opentelemetry/user-guide/use-managed-service-for-opentelemetry-to-submit-the-trace-data-of-python-applications?spm=a2c63.p38356.help-menu-90275.d_2_0_5_0.18ee53a4EGoGuS) |
| Plugin-Daemon | LoongSuite-Go Agent | [loongsuite-go-agent](https://github.com/alibaba/loongsuite-go-agent/blob/main/README.md) |

<Note>
設定を保存してトレースを有効にしたら、アプリを再実行し、監視サービスに新しいトレースが表示されるか確認してください。トレースは非同期で送信されます。設定の保存だけでは、トレースの到着は確認できません。

Agent アプリや [新しい Agent ノード](/ja/self-host/use-dify/nodes/agent#new-agent) を使うワークフローでは、デプロイ設定で `OPS_AGENT_TRACE_ENABLED=true` と `DIFY_AGENT_APPLICATION_TRACING_ENABLED=true` の両方を有効にしてください。詳しくは [環境変数](/ja/self-host/deploy/configuration/environments#llmops-トレース配信) を参照してください。これらのアプリでは **内容を収集** がデフォルトでオフになり、ワークフロー全体の入力と出力を制御します。それ以外のアプリでは、入力と出力が送信される場合があります。
</Note>

## 監視データリスト

Dify は処理を階層構造としてエクスポートします。メッセージの下には `llm` 呼び出しがあり、Chatflow のメッセージの下にはワークフローとノードの処理があります。トークン使用量のネイティブフィールドは、モデル呼び出しにのみ設定されます。

以下の詳細リストは、Dify の元レコードとメタデータを説明しています。エクスポートされるのは、関連する利用可能な値のみです。元レコード全体をそのまま送信するわけではありません。

Cloud Monitor は、Dify の Workflow/Chatflow/Chat/Agent アプリケーションからデータを収集することをサポートしており、ワークフローおよびワークフローノードの実行詳細、モデル呼び出し、ツール呼び出し、知識取得、さまざまなプロセスノードの実行詳細、会話やユーザー情報などのメタデータをカバーしています。
