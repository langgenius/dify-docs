## 設定

**入力変数** を定義してワークフロー内の他のノードからデータにアクセスし、これらの変数をコード内で参照します。関数は、宣言した**出力変数** を含む辞書を返す必要があります。

```python
def main(input_variable: str) -> dict:
    # 入力を処理
    result = input_variable.upper()
    return {
        'output_variable': result
    }
```

## 言語サポート

ニーズと習熟度に基づいて、**Python** と **JavaScript** から選択できます。どちらの言語も、データ処理用の一般的なライブラリにアクセス可能な安全なサンドボックス内で実行されます。

<Tabs>
  <Tab title="Python">
    Python には`json`、`math`、`datetime`、`re`などの標準ライブラリが含まれています。データ分析、数学的演算、テキスト処理に最適です。
    
    ```python
    def main(data: list) -> dict:
        import json
        import math
        
        average = sum(data) / len(data)
        return {'result': math.ceil(average)}
    ```
  </Tab>
  
  <Tab title="JavaScript">
    JavaScript は標準の組み込みオブジェクトとメソッドを提供します。JSON 操作と文字列演算に適しています。
    
    ```javascript
    function main(data) {
        const processed = data.map(item => item.toUpperCase());
        return { result: processed };
    }
    ```
  </Tab>
</Tabs>

## エラーハンドリングと再試行

失敗したコード実行に対する自動再試行動作を設定し、コードがエラーに遭遇した場合のフォールバック戦略を定義します。

<Frame caption="エラーハンドリング設定オプション">
  ![エラーハンドリング設定オプション](https://assets-docs.dify.ai/2024/12/58f392734ce44b22cd8c160faf28cd14.png)
</Frame>

**失敗時再試行** では、最大 10 回まで自動で再試行できます。再試行の間隔は最大 5000ms まで設定できます。一時的な処理の問題に対処するには、これを有効にしてください。

**エラーハンドリング** では、コード実行が失敗した場合のフォールバックパスを定義でき、コードが問題に遭遇してもワークフローの実行を継続できます。

## 出力制限

出力が次のいずれかの制限を超えると、ノードは失敗します。

| 出力 | デフォルトの制限 | 変数 |
|:--|:--|:--|
| 文字列の長さ | 400,000 文字 | `CODE_MAX_STRING_LENGTH` |
| 数値 | ±9,223,372,036,854,775,807 | `CODE_MAX_NUMBER`、`CODE_MIN_NUMBER` |
| 小数点以下の桁数 | 20 | `CODE_MAX_PRECISION` |
| オブジェクトのネストの深さ | 5 階層 | `CODE_MAX_DEPTH` |
| `array[string]` 出力の要素数 | 30 | `CODE_MAX_STRING_ARRAY_LENGTH` |
| `array[object]` 出力の要素数 | 30 | `CODE_MAX_OBJECT_ARRAY_LENGTH` |
| `array[number]` 出力の要素数 | 1,000 | `CODE_MAX_NUMBER_ARRAY_LENGTH` |

デフォルトでは、`object` 型の出力の中に、さらに 3 階層までオブジェクトをネストできます。ノードの出力そのものが 1 階層目に数えられ、配列は階層に含まれません。

結果が制限を超えた場合は、出力を減らすか、[制限を引き上げて](/ja/self-host/deploy/configuration/environments#コードとテンプレートの出力制限) ください。

## セキュリティ上の考慮事項

サンドボックス内のコードからも、Dify デプロイ内の他のサービスには接続できます。そのため、信頼できるコードだけを実行してください。信頼できないコードを実行する場合は、デプロイの管理者に依頼して、先に [サンドボックスのネットワークを隔離](/ja/self-host/deploy/configuration/environments#サンドボックスサービス) してもらってください。

## 依存関係サポート

コードノードは、Python と JavaScript 両方の外部依存関係をサポートします：

```python
# Python: numpy、pandas、requests などをインポート
import numpy as np
import pandas as pd

def main(data: list) -> dict:
    df = pd.DataFrame(data)
    return {'mean': float(np.mean(df['values']))}
```

```javascript
// JavaScript: lodash、moment などをインポート
const _ = require('lodash');

function main(data) {
    return { unique: _.uniq(data) };
}
```

依存関係はサンドボックス環境に事前インストールされています。Dify インストールで利用可能なパッケージリストを確認してください。
