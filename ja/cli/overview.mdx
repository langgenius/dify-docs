`difyctl` は Dify のコマンドラインインターフェース（CLI）です。ブラウザではなくターミナルから Dify アプリを操作できます。同じ作業を、コーディングエージェントやスクリプト、CI ジョブに任せることもできます。

セットアップは最初の一度だけです。`difyctl` をインストールしてサインインしたら、コーディングエージェントで `difyctl` スキルを使えるようにします。あとは、アプリの構築、実行、更新をエージェントに依頼します。

サインインには有効期限があり、[サインインの更新](/ja/cli/manage-sign-in#サインインの更新) には、人がブラウザで操作する必要があります。コードから実行するアプリが 1 つだけなら、代わりに [サービス API](/ja/api-reference/guides/get-started) を使ってください。サービス API のキーは更新する必要がありません。

始め方は次のとおりです：

- `difyctl` を初めて使う場合は、[クイックスタート](/ja/cli/get-started) の手順に従ってください。
- サーバーが Dify 1.18.0 に移行する前から `difyctl` を使っていた場合は、[Dify 1.18.0 へのアップグレード](/ja/cli/upgrade-across-1-18) から始めてください。
- セルフホストのサーバーが Dify 1.17.x 以前で稼働している場合は、[そのバージョンのドキュメント](https://github.com/langgenius/dify-docs/branches/all?query=release%2F) を参照してください。
