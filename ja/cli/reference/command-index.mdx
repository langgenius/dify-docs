コマンドのフラグを確認するには、`difyctl help <command>` を実行します。

コマンド内の `<mode>` は、`workflow` や `advanced_chat` などのアプリの種類です。各コマンドが受け付ける種類は `help` で一覧表示できます。それぞれの種類がどのアプリタイプに当たるかは、[アプリの検索](/ja/cli/run-apps#アプリの検索) を参照してください。

## サインインとアカウント

| コマンド | 機能 | 必要な条件 |
|:--|:--|:--|
| `login` | ブラウザでサインインする。 | |
| `logout` | サインアウトし、サーバー上にあるこのマシンのセッションを終了する。 | |
| `describe account` | サインイン中のアカウントを表示する。 | |
| `get account session` | 自分のサインインセッションを一覧表示する。 | |
| `delete account session` | 自分のセッションを 1 つ終了する。 | |
| `delete account current_session` | このコマンドの実行に使っているセッションを終了する。 | |

## アプリの検索と確認

| コマンド | 機能 | 必要な条件 |
|:--|:--|:--|
| `get console_app` | サービス API アクセスがオンのアプリを一覧表示する。名前や種類で絞り込むこともできる。 | |
| `describe console_app` | アプリの詳細と、アプリが受け付ける入力を表示する。 | サービス API アクセスがオン |
| `describe app_info <mode>` | アプリの名前、説明、アイコンを表示する。 | |

## アプリの実行

| コマンド | 機能 | 必要な条件 |
|:--|:--|:--|
| `run console_app <mode>` | アプリを実行し、結果を取得する。 | サービス API アクセスがオン |
| `upload console_app file` | 後の実行で渡すファイルをアップロードする。 | サービス API アクセスがオン |
| `stop run` | 進行中の実行を停止する。 | サービス API アクセスがオン |
| `get run event` | ワークフロー実行のイベントを追跡する。 | サービス API アクセスがオン |
| `describe run form` | 実行が一時停止した人間の入力フォームを表示する。 | サービス API アクセスがオン |
| `submit run form` | 人間の入力フォームに回答する。 | サービス API アクセスがオン |
| `get run` | アプリの実行を新しい順に一覧表示する。 | サービス API アクセスがオン、Workflow アプリと Chatflow アプリのみ |
| `describe run` | 指定した実行の入力、出力、エラー、所要時間を表示する。 | サービス API アクセスがオン、Workflow アプリと Chatflow アプリのみ |
| `get run node` | 実行の各ノードの処理を表示する。失敗したノードを探すときに使う。 | サービス API アクセスがオン、Workflow アプリと Chatflow アプリのみ |

## アプリの構築と変更

| コマンド | 機能 | 必要な条件 |
|:--|:--|:--|
| `create console_app <mode>` | 空の Workflow アプリ、または初期ドラフト付きの Chatflow アプリを作成する。 | エディター以上 |
| `set app_info <mode>` | アプリの名前、説明、アイコンを変更する。 | エディター以上 |
| `import console_app dsl` | DSL ファイルからアプリを作成または更新する。 | エディター以上 |
| `check console_app dsl` | DSL ファイルをインポートせずに、問題がないか検証する。 | エディター以上 |
| `confirm console_app dsl_import` | より新しい Dify バージョンのファイルなど、確認待ちのインポートを完了する。 | エディター以上 |
| `export console_app dsl` | アプリの DSL をエクスポートする。 | サービス API アクセスがオン、エディター以上 |
| `check console_app dependency` | アプリに必要な統合のうち、ワークスペースにないものを一覧表示する。 | サービス API アクセスがオン、エディター以上 |
| `get console_app env` | ドラフトの環境変数を一覧表示する。シークレットの値はマスクされる。 | サービス API アクセスがオン、エディター以上、Workflow アプリと Chatflow アプリのみ |
| `set console_app env` | 環境変数を追加または変更する。 | サービス API アクセスがオン、エディター以上、Workflow アプリと Chatflow アプリのみ |
| `delete console_app env` | 環境変数を削除する。 | サービス API アクセスがオン、エディター以上、Workflow アプリと Chatflow アプリのみ |
| `test console_app <mode>` | ドラフトをテスト実行する。人間の入力フォームで一時停止した実行は、`difyctl` から続行できない。 | サービス API アクセスがオン、エディター以上 |
| `test node <mode>` | ドラフトのノードを 1 つテストする。 | サービス API アクセスがオン、エディター以上 |
| `get node_type` | サーバーで実行できるノードタイプを一覧表示する。 | |
| `describe node_type` | ノードタイプの設定と既定値を表示する。 | |
| `get knowledge_base` | ワークフローで使えるナレッジベースを一覧表示する。 | |

| `restore console_app version` | 公開済みのバージョンをドラフトにコピーする。反映するには公開する。 | サービス API アクセスがオン、エディター以上、Workflow アプリと Chatflow アプリのみ |

## Agent ナレッジベース <Badge color="blue">Cloud</Badge>

`knowledge_fs` コマンドは、Dify で閲覧できる Agent ナレッジベースを読み取ります。コーディングエージェントにナレッジベースを読ませる方法は、[コーディングエージェントからナレッジベースを読む](/ja/cloud/use-dify/knowledge-base/use-knowledge-in-apps#from-your-coding-agent) を参照してください。

| コマンド | 機能 | 必要な条件 |
|:--|:--|:--|
| `knowledge_fs ls` | ナレッジベース内のドキュメント、または 1 つのドキュメントのセクションを一覧表示する。 | |
| `knowledge_fs tree` | ドキュメントとそのセクションを入れ子のリストで表示する。 | |
| `knowledge_fs find` | 名前またはメタデータでドキュメントを検索する。 | |
| `knowledge_fs grep` | ドキュメント内の語句を完全一致で検索する。 | |
| `knowledge_fs cat` | ドキュメント、またはその中の特定のセクションの内容を出力する。 | |
| `knowledge_fs stat` | 処理が完了したかどうかなど、ドキュメントの詳細を表示する。 | |
| `knowledge_fs diff` | 2 つのドキュメントを比較する。 | |

## ローカル設定とヘルプ

| コマンド | 機能 | 必要な条件 |
|:--|:--|:--|
| `help` | コマンドを検索し、そのフラグを確認する。 | |
| `version` | `difyctl` とサーバーのバージョンを表示する。 | |
| `get config`、`set config`、`unset config` | `difyctl` がサーバーの応答を待つ時間を表示、変更、またはリセットする。 | |
| `refresh cache` | サーバーのアップグレード後などに、サーバーのコマンド一覧を再取得する。 | |
| `delete cache` | キャッシュされたコマンド一覧を削除する。 | |
| `install skills` | `difyctl` スキルをコーディングエージェントのスキルフォルダにインストールする。 | |
